# speedrush 感知层「证据闪」问题图谱

> **本文是什么**：感知链（检测 → 跟踪 → 聚合 → 深度锚点 → 走廊）上「证据跨帧出现/消失」这一类问题的机制图谱与实测量化——定位感知层问题、判别修在哪层时的底稿。
> **本文不是什么**：不是修复设计（候选方向只在末节，方向立项时各建落地设计稿）；不是感知链的完整知识（模块机制见 `plugins/speedrush/CODE_WIKI.md`）。
> **信源等级**：L2——机制段以代码为准（文内 `file:line` 指向），量化段为 2026-10-17 两局实测（代码变动后数值需重测）。控制拍 P50≈50ms/拍，文中拍与 ms 可按此换算。

## 一、问题类定义：证据闪

感知层各证据源（车速度/距离、币组、奖励车横位、走廊）存在**证据不连续**形态，两个方向：

- **真证据消失**：有节拍空档、被守门清零、随轨道身份重建、随置信折扣损失——本图谱的主体（§二）；
- **假证据闪现**（幻影检出）：误检出现又消失，决策追逐后落空——本文仅点名该形态，未量化（探针未覆盖，专项待做）。

决策层的承诺制（CHANGE 意图需 `k_stay`/`k_up` 拍的持续证据，decision.json commitment 段，两值均为 2 拍≈100ms）以**稳定证据**为前提。实测断供是**段状**而非逐拍闪断（§三）：p1 全场无锚段 P90=36 拍（1.8s）、最长 141 拍（7s）——k=2 拍的承诺条件在短段内能凑齐，在长段内凑不齐；闪频越高、段越长，凑齐概率越低。判层判据：**修在哪层，看证据是「产生节拍」问题、「生命周期清零」问题、「单帧质量」问题还是「观测适用域」问题**——四类对应四种动法；对「闪」加兜底重试属于修在症状。

## 二、机制图谱（代码逻辑）

### 2.1 车速度与距离：锚间差分 + 簇跳变守门

速度不是像素估的。`v_close` 的唯一来源是**同一辆车前后两个深度锚点的区间差分**（`v_inst = (z_prev − z_new) / dt`，tracking.py:629-635）：需要连续两次锚点测量、间隔 ≥ `gate_eval_min_ms`（tracking 参数），到锚即发布 v_inst/v_close。由此三个环节：

- **节拍空档**：锚点清单来自深度 worker，实测锚龄 P50≈170ms（≈3.4 拍）、P90≈320~350ms、最长 583ms（§三）——锚龄即「清单没来」的时长。
- **簇跳变清零**（tracking.py:611-619）：新锚的 z 与旧锚差超过 `cluster_switch_m`（绝对阈值）判为「量错对象」，**锚、焦距锚、v_close、v_inst 全部清零**并丢弃该锚。两个代价：①清零丢弃该锚，速度重现需**到下两次锚点**（≈2×锚间 ≈300~500ms，比单拍更糟）；②绝对阈值对快接近必然段段误清——相对闭合 30 m/s × 锚间 300ms → 段间 Δz ≈ 9m，若阈值与该量级同量级，快关车每个新锚都会被判「量错」。
- **短区间估计噪声**：清零后首个成形区间可能很短，差分噪声大——实测一次短区间给出 3.02 m/s 的相对闭合（同场景真值量级存疑），短区间产物应携带不确定性。
- 亚门限跳变（tracking.py:620-628）丢弃单锚保旧锚，同样中断区间。

### 2.2 车横位：观测适用域（第四类问题）

`x_lane` 只在 `cy − y_h ≥ min_denom`（真源 gate0.json）时给（tracking.py:574-588 `_observe`；公式 world_model.py:93-97）。该门槛以下的检出（=min_denom 以下的弱读带）**横位为 None → 掉进 far_targets**（tracking.py:505-517 分流）——只有粗方向，没有横向数值。远场元素（奖励车平台、远币）整个可见生命大多落在该带内；地平线以上（denom ≤ 0）整帧丢弃。这不是节拍/清零/质量问题，是**观测几何/投影域覆盖**问题——修法是扩域、补投影或换估计源，与前三类动法不同。

### 2.3 币：置信跳动 + 单框组 + 到站依赖链

- **检测置信帧间大幅跳动**：日落逆光场景同一枚清晰可见的币，逐帧置信在 0.4~0.8 区间摆动、个别帧完全不检出（模型对该目标的稳定性问题，检测门槛 CONF，perception.py:37）。检测门槛以下的帧感知层无从谈起。
- **一排币只出最近一枚框**：币奖励以线状出现，检测器逐帧只框出最近的一枚。车一前进「最近的币」就换一枚——**轨道身份重建 → `rel_approach` EMA（tracking.py:447-448，Δcy/Δfid 纵向行运动）与年龄门槛（`min_obs_ticks`）反复从头累计**：这属于「观测适用域/身份连续性」类（§2.2 同类），不是清零类。
- **组置信聚合口径**：组置信 = 组内成员**最低**置信（coin_group.py:133）。单帧单币置信过检测门槛则 ≥ 地板，因此**地板（=检测门槛）在结构上不会拒组**；低置信组的代价走**折扣**（conf_min 贴近地板时坡度折扣大，decision.py:392-404）——折扣损失才是低置信组的实际扣分，不是拒组。
- **组价值下限**：观测 1~2 枚按整组 `coin_group_min_count` 计（decision.py:405-411）——价值侧对单框组已兜底。
- **到站时间的依赖链（单点故障放大器）**：币 t_miss 走全场地面流系数 k（decision.py:418-433）——k 取全体健康轨道（rel_approach>0 且 denom 在适用域）的**中位**，本帧无任何健康轨道时 k=None → t_miss 无限远 → **全场币组**只按远权计入、不进可达清单。单帧无健康轨道毒化全场币的到站时间。
- **幻影形态**（本文未量化）：误检币组闪现又消失，决策追逐后落空——同属证据不连续，专项待做。

### 2.4 走廊与收益报告：整拍缺席（机制未归因）

走廊供数（深度栅格）缺席的拍，收益评估整体返回 None（decision.py:819，唯一另一分支是 executed 缺席）。实测收益缺席与走廊缺席**逐拍严格相等**——executed 在这些局始终在场，两者是同一事件。**走廊缺席本身的原因本文未归因**（与深度栅格供数节拍同源的可能性未排除，独立门控可能性同样存在）——这是 §四.3 的前置问题。

### 2.5 汇聚点：决策层的持续证据要求

以上闪的形态在决策层汇聚：CHANGE 意图需要连续证据升级/维持（`k_stay`/`k_up` 各 2 拍，decision.json commitment 段），走廊收益场每拍重评但承诺只认稳定证据。k=2 拍（100ms）的承诺条件在段状断供的间隙内能凑齐，在长段（p1 P90=36 拍）内凑不齐——闪频与段长决定凑齐概率。

## 三、实测量化（2026-10-17 两局）

逐拍口径对两局 debug 会话实测（p1=…193629_p1 749 拍 / p2=…193714_p2 1324 拍；控制拍 ≈50ms；审计探针在感知实验区，此处只录结论）。口径分层：**全场无锚**（该拍所有车仪器都 UNKNOWN）≠ **目标车无锚**（快会车是单车链问题，与全场占比不是一回事，目标车口径需逐车归因，本文未做）。

| 指标 | p1 | p2 | 口径说明 |
|---|---|---|---|
| 车仪器 UNKNOWN 拍占比（全场口径） | 52% | 54% | 受影响拍数（处于无锚态），非翻面数 |
| 锚点集翻面（有锚↔无锚状态转移） | 15% 拍（113 次转移） | 31% 拍（413 次转移） | 转移数与受影响拍数是两个口径 |
| 全场无锚**段长** P50 / P90 / 最大 | 3 / 36 / 141 拍 | 2 / 8 / 49 拍 | 段状断供，非逐拍闪断（判层关键） |
| 锚龄 P50 / P90 / 最大 | 167 / 317 / 550ms | 178 / 350 / 583ms | ≈3.4 / 6.3 / 11 拍 |
| 币组可见拍占比 | 16% | 38% | **与人工基线 15%/34% 一致**——币组稀疏是常态，不是病 |
| 收益报告缺席 = 走廊缺席 | 14% | 8% | 逐拍严格相等（§2.4：同一事件） |

p1/p2 的两倍以上差异（币可见、翻面率）大概率来自场景/阶段（p1 币稀疏段多），读数时按场景分侧，不合并成区间。

**对决策层的传导（修正后的口径）**：k_stay=k_up=2 拍的承诺条件在 p2 的短断供段（P50=2 拍）内能凑齐；p1 的长段（P90=36 拍）内凑不齐。所以「闪」的实际代价是**场景依赖的凑齐概率下降**（长段场景），不是无差别「永远凑不齐」——快会车追尾案（p1 帧 57~61，速度在 0.3s 前才成形）发生在长断供段内。

## 四、修的方向（候选，未定案）

与图谱的覆盖矩阵（含暂不立项项）：

| 图谱条目 | 类 | 方向 | 状态 |
|---|---|---|---|
| §2.1 锚供给节拍空档 | 产生节拍 | 方向 1（部分：节拍本身不动，桥接覆盖空档） | 候选 |
| §2.1 簇跳变清零 | 生命周期清零 | 方向 2 | 候选 |
| §2.1 短区间噪声 | 清零代价 | 方向 1（不确定性标记） | 候选 |
| §2.2 横位适用域 | 观测适用域 | 无——暂不立项（远场粗源已覆盖奖励车；远币并入需另一轮） | 已记 |
| §2.3 置信跳动 | 单帧质量 | 方向 4 | 候选 |
| §2.3 身份重建反复清零 | 观测适用域/身份连续性 | 无——暂不立项（依赖方向 2 的身份判别先立） | 已记 |
| §2.3 k=None 级联 | 级联 | 无独立方向——**修法与方向 3 同构（k 短保持/衰减），并入方向 3 立项** | 已记 |
| §2.4 走廊缺席 | 产生节拍（未归因） | 方向 3（前置=§2.4 归因） | 候选 |

**方向 1（速度像素桥）**：锚点链无有效区间时以像素运动桥接 v_close。信号选型：`rel_approach`（tracking.py:447-448）是**纵向行运动**（Δcy/Δfid，正=接近）——正是闭合方向，像素 t_meet 已消费它（decision.py:329-338），桥接物理口径同一真源；bbox 高度/面积变化率（∝ d(1/z)/dt）是另一候选，需标定。两个前置问题：**(a) 双源仲裁**——锚速度与像素速度的进入/退出条件不定，来回切换本身是新闪源；**(b) 不确定性标记**——清零后首个短区间噪声大（3.02 m/s 实证），桥接段应携带不确定度供决策层降权。
**方向 2（簇跳变动态门）**：两个候选，便宜的在前——**(a) 动态门**：`cluster_switch_m` 绝对阈值改为随 dt 与 v_prior 缩放（快接近 × 锚间 300ms → 段间 Δz ≈ 9~10m，绝对阈值必然段段误清；动态门可能覆盖大半案例，无结构改动）；**(b) 分级清零**：按组合证据（尺度一致性、track id、v_prior 合理性）区分「换对象」与「同车修正」——注意已知反例：同车道前后两车 x 近似连续而 z 跳变是真换对象，单凭 x 连续性会把 A 车速度安到 B 车上，比清零更重。
**方向 3（走廊短保持 + k=None 级联）**：前置=§2.4 归因（缺席机制、单拍还是连续段——段长决定保持窗口）。与「对闪加兜底=修在症状」的张力：若归因为锚龄同源的节拍问题，短保持是节拍修复前的过渡而非兜底，判层结论在归因之后。保持上限、陈旧衰减、与节拍修复的先后关系在立项时定。
**方向 4（币置信稳定性）**：模型专项之前有更便宜的层——**聚合层跨帧置信 EMA/迟滞、组置信取可见帧上分位**，可用两局数据离线回放先验证收益再决定是否动模型。
**暂不取的选项空间（记一笔）**：承诺制容忍化（证据迟滞/衰减计数）——k_stay/k_up 已是 2 拍的小值且处于 A/B 收案态（decision.json commitment 段运行态），本轮不动；若方向 1~4 落地后凑齐概率仍低再评。

方向 1/2 属锚点链结构改动（感知层契约面），方向 3 属走廊供数，方向 4 属聚合/模型——各自独立立项，不混一个改动里。
