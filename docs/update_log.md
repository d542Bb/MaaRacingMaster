# MaaRacingMaster 更新说明

> **本文是什么**：面向玩家的更新说明——装上新版后能看到、感到什么不同。GitHub / CNB Release 正文由此抽取。
> **本文不是什么**：不是开发日志。内部重构、测试、CI、文档与实验过程不在这里——过程归 commit message，结论归各自 home。
> **收录判据**：写每一条前自问「**玩家能看到什么不同**」——答不出就不写。判据细则见 [`README.md`](./README.md)「update_log 收录判据」。
> **版本标题格式**：`### vX.Y.Z[-dev.N] 一句话主题`——`scripts/release/extract_changelog.py` 按此抽取，格式不可改。
> **信源等级**：L4（历史）—— 可作「当时对外发布了什么」的依据；**不是**当前形态的依据（回真源与 L2 文档核对）。
> **继承**：通用协作与信源规则见 [`AGENTS.md`](../AGENTS.md)。

## 2026-09-11

### v0.22.0-dev.1 项目更名 MaaRacingMaster + 内部架构收敛 🏷️

- **⚠️ 升级前必读——两处名称变更，数据不自动搬迁：**
  - **软件更名：** `MaaRacingAssistant` → `MaaRacingMaster`（界面短名 `MaaRM`）。入口程序、发行包名、窗口标题、日志文件前缀一并变更。
  - **用户数据目录换名：** 运行期数据根改为 Roaming 下的 `MaaRacingMaster` 文件夹。**新版本不读取旧目录**——直接升级会让偏好回到默认、鉴宝历史记录重新起算。需要保留历史的用户，请先用文件管理器把旧文件夹整体改名或复制为 `MaaRacingMaster`，再启动新版本。
- **说明：** 本版重心在内部收敛（识别真源迁移、截图统一、进程内时钟分族、构建体积闸门），玩家可见的交互与活动流程无实质改动。

## 2026-07-20

### v0.6.0 GPU 推理加速 + 流程重构 🚀
