# ADR-0021（arch-core）：一次程序启动一个会话——取证按会话归档，开关不换身份

- **状态**：`accepted`
- **日期**：2026-11-06
- **决策者**：用户（方向裁决：会话优先目录；不做 v4 兼容，旧数据手动清理或重录）
- **相关**：ADR-0019（运行级统一；本 ADR 取代其「运行编号作为唯一身份」与「调试目录按运行编号分组」两部分）、ADR-0010（记录流三分）、[`core/CODE_WIKI.md`](../../maaracing_master/core/CODE_WIKI.md)（日志 / 调试流）、[`session_layout.py`](../../maaracing_master/core/session_layout.py)

## 背景

v4 的调试与日志身份依附于「日志记录」开关：开关打开才生成会话目录，关闭时调试退回每轮时间戳；同一进程里反复开关会换会话。调试目录还带 `_rN` 轮次后缀，模块自有的取证又另立 `debug/<模块>/<局时间戳>_pN/`，回放必须按模块各自的时间戳与目录形状猜对齐。一次启动连跑多局时，轮次被拆进不同目录，会话级的证据拼不回来。

## 决策

1. **一次程序启动 = 一个会话编号**：`YYYYMMDD_HHMMSS`（同秒撞上既有日志或调试目录时追加 `_2`、`_3`），进程启动时生成一次，与日志/调试开关状态无关。日志、流水、性能、调试共用它；轮次序号只作为记录字段，不进入任何路径。
2. **取证目录按「会话 → 模块 → 行为」分层**：`debug/<会话>/<模块>/<行为>/`。行为目录必须有 `manifest.json`（会话、模块、行为、起止时间、帧索引相对路径），帧索引至少含序号、单调时刻、相对路径；会话根 `index.jsonl` 只记段边界、阶段与开关，不承载模块私有帧。路径中不得出现 `_rN`。
3. **开关只决定有无文件，不换身份**：日志开关控制 `logs/<会话>/` 下是否写入，调试开关控制 `debug/<会话>/` 下是否写入；中途任一开关切换都回到同一会话目录。日志中途重开时流水序号在同文件内续写，不重置、不新开会话。
4. **谁产帧谁写索引**：模块自己取证（如极速狂飙控制局）时，帧与索引留在该模块的行为目录，行为清单声明索引路径；统一流只记行为目录与段边界，不复制帧。统一流负责落盘的模块，由统一流写行为清单与帧索引。
5. **旧布局不读**：`debug/<token>_rN/`、`debug/<模块>/<时间戳>_pN/` 不再被运行时或回放读取；需要样本时重录，旧目录由维护者清理。人工录制语料仍留在用户资产区，不迁入调试会话。
6. **回放只认清单与最小帧索引**：播放器枚举 `debug/<会话>/<模块>/<行为>/manifest.json`，按索引的帧号/单调时刻对齐流水，不依赖模块私有格式。

## 后果

**收益**：同一进程的多轮证据落在同一会话，日志、流水、性能与帧可按会话与双时钟对齐；开关切换不再产生「另一个会话」，排查时不需要猜时间戳；模块增删行为目录不影响其他模块；回放与模块私有格式解耦。

**代价与约束**：模块必须遵守行为命名白名单并写清单；轮次信息只能进元数据，不能再靠目录名区分；旧数据不可回放，需要重录；行为目录跨多轮时要能用自己的索引区分段。

**被否方案**：① 开关切换即新建会话——同进程证据散落，且关日志时调试没有稳定身份；② 保留 `_rN` 目录——轮次与会话粒度不一致，多轮被拆散；③ 把模块帧复制进统一目录——同一帧两份，违背 ADR-0010 的取证分工；④ 自动迁移 v4 旧目录——旧数据没有会话身份，迁移只能伪造归属，不如重录。
