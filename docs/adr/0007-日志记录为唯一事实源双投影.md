# ADR-0007：日志记录为唯一事实源，文件与 GUI 是投影

- **状态**：`accepted`
- **日期**：2026-09-21
- **决策者**：用户（契约批准与方案 A 裁定）
- **相关**：`core/CODE_WIKI.md` §1.5.2（实现现状）；契约冻结 `81c2eb2`；落地链 `3671551`→`9199527`→`ed0cd25`→`92f03b6`→`774b1b6`→`b47ef41`

## 背景

GUI 运行日志长期从**渲染后的文本行**反推结构：前端用措辞正则锚点（`SECTION_ANCHORS`）分段、关键词表着色、按行数推导警告/错误标记。日志越修越像 debug 输出，每改一处措辞就可能弄坏一处前端行为；「到处改输出」被用户判为打补丁。同时后端只有字符串日志 API，插件的阶段性工作（一场循环、一个阶段）在 GUI 里散成平铺行，无边界、无终态。

## 决策

1. **记录是唯一事实源**：core logger 环形缓冲存结构化记录（`schema_version/seq/event_type/group_id/level/kind/title/message/fields/outcome/…`）；文件与 GUI 文本都只是投影——文件=全事件流 + GH 风格 `::group::` 标记，GUI=仅 `log` 事件。
2. **组边界由业务层声明**：插件经 `logger.group()` 句柄（或模块内 `_tlog/_open_grp/_end_grp` 形态）宣告开组/收尾；core 不枚举、不感知业务阶段。跨线程传捕获的 `group_id`。
3. **前端不得从文本推导状态**：卡头徽章只吃 `group_start/group_end` 的 `outcome`；措辞锚点、关键词着色、按行数推导全部退役。卡片只来自组事件，无组散行=裸行，级别由文字色承载。
4. **结构完整性优先于体量控制**：组事件豁免通道级别门（防无头组）；`end` 首调定终态、重复调幂等；进程收尾（`Logger.close()`）把未关组补 `incomplete`。
5. **fields 先净化后入库**（标量、限量、敏感键剔除），违规只进内部计数，不记日志、不抛异常；一切动态文本经 `textContent` 落 DOM，禁 `innerHTML`。

## 后果

**收益**：措辞与呈现解耦（改文案不碰前端）；GUI 卡片有真实生命周期与终态；复制/导出含 `seq/ts/group_id`，与文件日志可互相定位；协议对插件的复用成本 = 声明组边界与终态。

**代价与约束**：前端不得再引入任何按文本内容推导结构的机制（锚点表/关键词表/行数推导）；插件的阶段性 INFO+ 日志必须走组句柄，裸 `logger.log` 受结构锁测试约束（白名单外必红）；`schema_version` 是 GUI 兼容判据，改记录形状必须升版本；过渡期 `fetch_logs` 的 `lines` 字段是派生投影，不得当第二数据源吃。

**被否方案**：① 逐处改日志措辞压信息——打补丁，无复用核心（用户否决）；② 方案 B：通道级「当前组」隐式注册表——隐式状态在并发派发下串组（用户裁定不批准，采显式句柄方案 A）；③ 不双写 JSONL——v1 无机器读盘消费者，出现时加伴生文件不改主格式；④ 常驻跑马灯展示长标题——长驻面板视觉噪音（WCAG 2.2.2），改悬停展卷。
