# ADR-0008：路面平面初始化候选点必须经独立语义判据，几何域不等于物理语义

- **状态**：`accepted`
- **日期**：2026-10-14
- **决策者**：用户（GPT 对抗复核支持，修复落地并回归验证后按用户条件落笔）
- **相关**：`plugins/speedrush/CODE_WIKI.md`「平面拟合」条目（实现现状）；`depth_geo._pick_seed_candidate`（具体判据）；AGENTS.md 诊断三原则

## 背景

路面平面拟合域是**几何范围**（|X|<4m、Z 4~30m、排除自车 3D 框），域内点的来源没有独立于拟合本身的语义判据——护栏面点落在几何域内即进拟合。2026-10-02 换装的列剖面特征种子挡不住贴右护栏场景：护栏沿纵深后退，逐行深度行为与路面同型，**躲得过深度增量判据**；右半特征点自成一个比路面陡 5~28° 的斜面（比路面高 0.4~1.9m，3034/3178 实测）。全域单种子是「左路 + 右墙」两簇的最小二乘折衷，被拽歪 5~6°；后续走廊 15cm 内点带以错误平面为参照，**稳定收敛到错误答案**——大量点共享同一系统性误分类时，错误平面反而显得稳定（种子选出 3.4 万点不是证据充分，是系统性误分类）。后果链：质量门拒 → 全帧弃权 → 深度供数断供 → `hold:no_candidate`（消极驾驶的三个杀手之一）。这已是同一病理的第二次现形（000660 旧病理同源，金标帧仓已不在盘无法复放，但 20261012 坏帧语料覆盖同类场景）。

## 决策

1. **几何域不等于物理语义**：点落在车辆附近的拟合范围内，不意味着它属于路面。参与路面平面初始化的候选点，必须通过**独立于当前待估平面**的判据——禁止引入消费待估平面的循环判据（剪枝用被评平面选点再证明该平面）。
2. **种子多候选竞争**：特征种子按全域/左半/右半三候选拟合，以紧容差（半走廊容差）内点数选优。路面是一个平面——半幅一致时全域候选胜出（行为不变），墙面簇让全域候选紧内点骤降、单一一致面胜出（贴栏帧 58k vs 97k 实测）。
3. **护栏保持墙体感知角色**：墙退出种子拟合不等于退出点云——找边、挖除缝、障碍链路原样消费墙点（拒帧修复后边读数仍在，回归实证）。

## 后果

**收益**：贴栏帧不再全帧弃权。75 帧真实语料新旧对照回归（git HEAD 旧实现 vs 本实现）：26 帧从质量门全弃权恢复供数（新滚转全部落在 −2.2°~+3.9° 合理带）、14 帧被拽歪的平面角修正（如 −5.64°→−1.24°、+1.99°→+0.19°）、零帧从放行退化为弃权或丢失边数；干净基准帧行为逐位不变（滚转差 0.0004°）。

**代价与约束**：后续开发者**不得**回退到「全域单种子 + 几何域圈地」——更换拟合器、调整阈值或优化性能时，种子必须保持多候选竞争与紧容差选优，否则贴栏场景复发；判据只能来自独立于待估平面的量（几何域窗、跨簇一致性），不得加"按被评平面滤点"的循环机制。

**被否方案**：
- ① 候选点绝对高度带（相机安装高度 ± 坡度界逐点过滤）——**被数据否**：护栏仅 ~1m 高，墙面点相机高度全部物理合理（贴栏帧右侧 Z[4,8) Y 中位 1.28），过滤只割 6 点、种子纹丝不动。
- ② 恒深段过滤（Δz 低于理论增量的分数即不标路点）——**被数据否**：拽歪种子的点通过了增量判据（护栏沿纵深后退非恒深），割 7.5k/12k 点种子不动。
- ③ RANSAC / 通用鲁棒拟合——不采用：鲁棒拟合处理离群点，不能保证在一大片结构一致、数量占优的错误候选中选中路面；且引入随机性与新阈值（GPT 裁决）。
- ④ 迭代高度剃刀（按 hgt 逐层挖墙）——不采用：自增强循环依赖（剪枝用被评平面选点再证明该平面）。
