# ADR-0015 紧急停止的启用范围：只在程序接管操作期生效

- **状态**：`accepted`
- **日期**：2026-11-03

## 背景

紧急停止（同时按下键盘任意 ≥2 键即停）是全局后台轮询。人工驾驶/录制阶段，键盘操作本身就是多键组合（速跑键盘驾驶 W+A 即两键），与急停判据直接冲突：要么录制被误停，要么键盘录制不可用。

## 决策

急停的按键检测只在**程序接管输入**时生效。模块通过 `ActivityModule.manual_input_active()` 声明当前是否处于人工驾驶/录制阶段（默认 `False`，异常按 `False` 处理）；`controller._emergency_stop_loop` 在该方法为真时跳过按键检测，开关本身与轮询线程不变。

## 后果

- 人工驾驶/录制阶段没有键盘急停；停止仍可经 GUI「停止」按钮触发（模块响应 `_running`）。
- 新增带人工驾驶阶段的模块必须覆盖 `manual_input_active()` 返回实况，否则急停会在人工阶段误触发。
- 程序接管期（深度几何、全程直行、宏回放）的急停行为不变。

## 证据

- 实现：`maaracing_master/core/base.py`（`manual_input_active`）、`maaracing_master/core/controller.py`（`_emergency_stop_loop` / `_manual_input_active`）、`maaracing_master/plugins/speedrush/module.py`（录制阶段置位）。
- 回归：`tests/test_controller_emergency_scope.py`（人工阶段跳过、程序阶段保留、无模块/异常回落检测）；`tests/test_speedrush_macro.py` 的录制链路用例。
- 需求口径：维护者 2026-11-03 明确「紧急停止只对程序操作时启用」，起因是宏录制的键盘映射（W+A 两键）。
