这一版预览锁定的口径

  • 候选集：任务列表里声明了看板的模块，按任务列表顺序排列；内置步骤永不入列；未加入列表的模块不出现。
  • 选中：显式、会话内；队列变化只校正当前模块（被移出就夹到相邻项），翻页由用户触发。
  • 运行态：当前页由用户控制；运行中的模块在通往它的箭头上打绿点，点箭头切换过去，到达后页码前打绿点。
  • 边界：只有一个看板时左右箭头保留并置灰，页码作为运行状态位；没有候选时保留空态槽位，下方实时预览保持原位。
  • 生命周期：只有当前看板挂载并轮询，切走即卸载、停止拉数；看板不依赖模块实例。
  • 内部内容：模块返回声明式 block（stats / list / text / path / action），中心统一渲染与转义；core 只校验通用 block 形状与版本，不持有模块业务字段。

极速狂飙页签是形态示意；当前唯一声明看板的是鉴宝，极速狂飙接入后会进入候选集。
