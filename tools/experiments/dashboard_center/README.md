# dashboard_center —— 数据页看板中心形态预览

status: active

## 目标

数据页需要一个稳定的看板主体：候选集由任务列表和模块声明共同决定，当前看板由用户显式翻页选择；固定槽位承载空态、单模块、多模块三种边界。

本目录是前端设计评审用的静态形态预览，不是外部系统事实实验，也不接生产数据。生产侧后端已落地看板资格与通用内容路由（`get_module_dashboard` + block 校验，见 `core/CODE_WIKI.md` §1.20），本目录只验证看板中心的形态与边界。

## 状态

`preview.html` 顶部切换三种状态：

- **无模块声明**：候选集为空，槽位保留空态，下方实时预览保持原位。
- **单模块声明**：只有鉴宝，左右箭头保留并置灰，页码 1 / 1。
- **多模块声明**：鉴宝 + 极速狂飙（示意页），按任务列表顺序翻页；运行中的极速狂飙在通往它的箭头上打绿点，点箭头切换过去，到达后页码前打绿点。

## 口径

- **候选集** = 任务列表里的模块 ∩ 声明了看板的模块；内置步骤永不入列；未加入列表的模块不出现。
- **选中**是显式、会话内的 UI 状态；队列变化只校正当前模块（被移出就夹到相邻项），翻页由用户触发。
- **运行态**：正在跑的模块在通往它的箭头上打绿点，点箭头切换；到达后页码前打绿点。
- **生命周期**：只有当前看板挂载并轮询，切走即卸载、停止拉数；看板不依赖模块实例。
- **核心边界**：core 提供统一的看板路由与 block 形状校验，不持有模块业务字段；渲染、选中与生命周期在前端。

## 内部内容声明（原型）

两块看板由同一套 block 数据渲染，模块只决定 block 的组合与文本，标题、布局、间距、配色、翻页与生命周期由看板中心统一：

| block | 用途 |
|---|---|
| `stats` | 指标格：`label` / `value` / `tone` / `sub` / `dots` |
| `list` | 明细行：`leading` / `badge` / `text` / `trailing` |
| `text` | 说明段落 |
| `path` | 等宽路径或标识 |
| `action` | 标准动作按钮（如打开用户数据目录） |
| `today_stats` | 兼容块：pre-contract 模块的今日统计原始数据；当前鉴宝冻结桥使用，前端对应渲染器解释 |

当前契约：模块实现版本化的 `read_dashboard()` 返回该 payload；core 用共享 schema 校验版本与 block 形状；前端只按白名单 block 渲染并对文本转义。新增视觉原语时扩展共享 block 类型；模块内容通过 block 组合表达，后端不下发 HTML。动作只走标准动作白名单，模块不持有任意 RPC 或 URL 能力。

鉴宝不实现 `read_dashboard()`：它现有的 `read_today_stats()` 覆盖即被当作旧模块资格，core 把它包成 `today_stats` 兼容块，预览里用目标 `stats` + `list` 表达同一张看板。极速狂飙之后按标准 block 接入。

## 打开

直接用浏览器打开 `preview.html`（`file://` 可用，无网络依赖）。页面是自包含的静态 HTML/CSS/JS，样式取正式前端的 token 与卡片语汇，但不引用生产代码。

## 退役

设计定稿后，结论进前端设计稿 / ADR 与正式实现，本目录按实验区生命周期删除；不要把预览路径写进正式知识。
