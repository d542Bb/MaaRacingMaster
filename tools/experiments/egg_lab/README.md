# egg_lab —— 员工守则彩蛋调试试验区（重建 v2）

status: active

## 目的

生产实现（6a048c2）躲避按钮的实测反馈：**按钮被操作行束缚，逃不起来**（躲避场只有
底行一条窄带，x 轴位移，观感是"被困住"而不是"逃跑"）；但也不能跑出弹层、跑没影。

## 本轮改动（[lab-iter2]，确认后回生产）

- **躲避场 = 整张弹层卡**：按钮在卡内二维逃跑（不再限于底部操作行），可以扑到正文上——
  transform 不改布局，滚 动/点击不受影响；
- **"不能跑太远"两道闸**：①位移上限 `reach = 110px`（从布局位算起，spring 回家行为保留：
  光标退开 120px 半径外，按钮 0.62s 回弹归位）；②硬钳制在卡内 `inset = 12px`，任何时刻
  视觉矩形不得越过卡缘；
- 保留 v1 修复：taunt 换字钉 `min-width` 防跳动；探测基准改为**按钮视觉中心**（它感知
  "你的手在接近它"，而不是场中心）；
- 状态机不变：接近 66px 计一次逃跑，4 次后 relent 放行（好吧。你走吧。）。

## 自检

「跑自检」断言：抽样形状、掉落混入频率（25 点 5 中）、onClose 单次、躲避状态机
（4 次 relent 放行）、**出界扫掠**（指针绕按钮一圈逐位置断言视觉矩形在卡内 inset）与
**跑距断言**（位移 ≤ reach）。

## 本轮改动（[lab-iter4]，确认后回生产）

- **堵逃课出口**：`openModal` 新增 `closeOnOverlay` 选项（默认 true 不影响既有弹层），
  守则弹层传 false——点空白不再关闭。Esc 仍可关（键盘可达性保留，"它总能放你走一条路"）。
- **抓到 = 亮下一句**：点击按钮不再直接关门，改为逐句亮起
  `EGG_CATCH_LINES = ['抓不到','差一点','太慢了','别追了','你为什么执意要走','好吧。你走吧。']`；
  末句亮起后放弃躲避（gave），**再抓一次才关门**。躲避本身不再换字，只有抓到才推进。
- 保留 v2/v3：整卡二维躲避、撞墙滑移、reach 140、卡内 inset 12、min-width 防抖、
  关闭绿点回响、掉落短语池。

## 自检

「跑自检」断言：抽样形状、掉落混入频率、**抓捕序列**（逐句亮起 + 末句后不逃）、
**点空白不关**、**通用弹层点空白仍可关（回归）**、onClose 单次、末句后再抓关门、
绿点回响、出界扫掠与跑距上限。
