# egg_lab —— 员工守则文案重写 + 彩蛋效果

status: active

## 目标

① 员工守则文案重写：去掉鉴宝域条目（出价/房产/对手/YOLO），全部落到 GUI 自身真实元素；整体从"幽默为主"调向"规则怪谈式微恐"，追求后劲。② 彩蛋效果：守则逐条渐现、每次打开随机抽样、第 0 条、标题呼吸、按钮 hover 换字、关闭后状态栏绿点回响、掉落文字池混入怪谈短语。

## 文案手法（规则怪谈文体，2026-09-22 按文体成熟套路撰写）

- 执行体口吻，全文不许笑——幽默只能来自"过度冷静"本身；
- 每条暗示一起从未解释的事件（"有人替你停止了""是确认"）；
- 具体数字制造真实感（3:33、两下、72 小时弃用）；
- 恐惧锚点全部是 **GUI 真实存在的元素**（静音恢复/日志轮转/状态栏绿点/自动关机/版本号 git 推导/数据页看板）——"我认识它"才后背发毛；
- 数字母题贯穿：第 6 条"不要清点数量" ↔ 末条"说明你数错了"；
- 第 0 条 meta 规则 ↔ **随机抽样效果**互相成就：用户重开守则发现条目变了，第 0 条早已告知"你读到的版本就是你需要读的版本"。

## 效果与挂点（生产实现方案）

- `EGG_RULES` 拆为 `EGG_RULE_META`（第 0 条固定）+ `EGG_RULES_POOL`（池，抽 8）+ `EGG_RULE_LAST`（固定末条）；
- `.mra-modal-rule` 逐条 fade-in（stagger 100ms，reduced-motion 退化为直接显示）；
- 标题 letter-spacing 呼吸动画；按钮 hover 双 span 换字（确定要退出吗？→ 现在退出还来得及）；
- `modal.js` `openModal` 增加可选 `onClose` 回调（3 行），守则关闭后状态栏绿点连闪两下（呼应第 5 条）；
- `FALLING_EGG_TEXTS` 从 null 占位填入短语池（'3:33' / '不要清点' / '它记得你'），掉落时低概率混入版本号流。
