# 换道完成判据 — 只读判定稿

status: spec（判定器未实现；阈值一律未知/待标定；不改控制链）

> **本文是什么**：「并线是否完成」的离线验收规格——证据来源与时间基、三值结论、
> 无法确认时的退出、验收指标与留痕。判定器与探针以本文为唯一口径。
> **本文不是什么**：不是控制规则（不改路线层/执行层任何判据）；不引入新阈值；
> 不作收益结论。现状实现是 `route._tick_merging` 的完成判据（位置进带 + 横速落稳），
> 本文只把它拆成「值 + 证据类」，不重写它。
> **信源等级**：L4（实验设计与过程证据）。结论兑现后折入 `CODE_WIKI.md` / ADR，
> 不进正式正文。统计前置检查沿用 [`../README.md`](../README.md) 的四问
> （同层、归一、身份先于统计量、量变不变）。

## 0. 不变量（先于任何统计）

1. **判定因果**：某一拍的结论只能使用 ≤ 该拍的证据。事后核验证据单列保存，
   不得回流到决策拍的结论里——否则等于用未来信息替当时的判断背书。
2. **证据分三等**：新鲜测量 / 保持值 / 预测值。保持值可以当位置先验，
   **不构成新的运动证据**（读数被冻结出来的「速度为 0」不是车停了）。
3. **结论三值**：`完成` / `未完成` / `无法确认`。缺证据或证据互相矛盾时入
   `无法确认`，不得为了二分强行归入完成或未完成。
4. **阈值不写死**：本文不复制任何数值；现有配置容差是真源。凡需阈值处标
   「待标定」，并写明标定所需的统计量（见 §8）。

## 1. 状态来源与时间基

三种时间必须能分别回答：**观测发生时间**（测量发生在哪一帧）、**处理时间**
（哪一拍消费了它）、**状态时间**（估计值指向哪一刻）。

| 状态量 | 生产位置 | trace 列 | 状态时间 | 证据类判定 |
|---|---|---|---|---|
| 路心横位读数 | 深度供数链 | `road_offset` + `ro_hold` + `ro_source` + `dgeo_age` + `dgeo_new` | 观测帧时刻（读数无外推） | `dgeo_new=true` 且 `ro_hold=false` = 新鲜；`ro_hold=true`（`pair_slot`/`wall_occl`/`memory`）= 保持；复用旧证据（`dgeo_new=false`）= 保持 |
| 粗层横位 | 决策层 | `coarse.ego`（选择帧横位；与 `road_offset` 同源，相差一个 z=0 中心线偏移） | 同路心读数 | 继承上一行 |
| 执行层横位/横速 | 执行层 α-β 状态 | `executed_lane`、`v_lat_est`、`lat_ctrl` | 当前拍（模型步推进） | 预测值；带重锚史与模型步长 |
| 路线层位置/速率 | 路线层 | `route.ref`、内部 `v_ref`/`v_est_lane_s` | 当前拍 | 位置继承粗层；速率 = 相邻拍差商，证据类取**两端较差** |
| 参考系影子 | 影子链 | `lateral_frame`（`x`/`x_model`/`v`/`fresh`/`lane_age`/`theta_age`） | 当前拍 | 观测 + 预测混合，按 `src`/`fresh` 分列 |
| 事后跳变分类 | 决策层（只记录） | `ro_hop`/`ro_v_obs`/`ro_gap_s` | 两次新鲜读数之间 | 事后核验侧原料，不进决策 |

时间基要求：每拍有 `fid` 与 `ts_ns`；深度证据年龄由 `dgeo_age` 给出（观测时间 =
本拍 `ts_ns` − `dgeo_age`）。**判定用到的每个量都必须能回答「来自哪一拍、几岁了」**；
答不出的量按「证据不可用」处理，不得按 0 或按「上一拍的值」默认可信。
当前缺口：路心读数没有独立的总年龄列（只有 `dgeo_age` 与来源名），
按来源推断的保持时长不等价于观测年龄——缺口登记为 G3，不在本稿里补列。

## 2. 证据分类

- **新鲜测量**：同拍消费的新证据。可提供位置证据，也可与上一拍新鲜测量构成运动证据。
- **保持值**：`ro_hold=true` 或复用旧证据。允许：位置先验、参考系连续性判断。
  禁止：作为「车在动 / 车停了」的证据；与相邻拍做差得到的「速度」记为
  `保持差商`——相邻两拍读到同一个冻结值，差商恒 0，与车是否真的停住无关。
- **预测值**：执行层/影子模型外推。允许：估计当前状态；必须同时给出预测年龄
  （自上次校正）与重锚史。不确定性的数值口径暂缺 → 标「待标定」，不用拍的常数代替。

## 3. 完成判定

现状实现：`|v_ref − 目标道| ≤ finish_tol_lane` 且 `|v_est_lane_s| ≤ finish_v_tol_lane_s`。
本稿保留这两个容差为真源，只增加**证据类**维度：

- **位置项**：值为 `v_ref` 与目标道之差；证据类由 `v_ref` 继承（新鲜 / 保持 / 预测）。
- **速度项**：值为 `v_est_lane_s`。只有差商两端都是新鲜测量，才记为「实测横速」；
  任一端是保持值，记为「保持差商」，不满足速度项。
- 冲突不硬判：位置来自保持值、速度来自实测（或反之）且结论相反 → `无法确认`；
  不用「哪路更新就信哪路」的临时规则。

| 位置项 | 速度项 | 结论 |
|---|---|---|
| 新鲜或预测（年龄在案）且进带 | 实测横速且落稳 | 完成 |
| 进带 | 保持差商 / 缺证据 | **无法确认**（不得报完成） |
| 进带 | 实测横速未落稳 | 未完成（还在过冲） |
| 未进带 | 任意 | 未完成 |
| 位置与速度互相矛盾 | — | 无法确认 |

「后续观测支持完成」≠「当时判完成是对的」：本节只判**当时**归入哪一类，
事后是否真的到位由 §5 的核验列单独给出，两列分开统计。

## 4. 无法确认时的退出

- 唯一的**纯时间**退出仍是并线超时（阈值真源在配置，本文不复制数值）。
  本稿不新增年龄阈值、不引入置信区间。
- 重建（换纪、参考道失去几何）与撤销各有既有判据；判定稿只登记其结局与原因码，
  不评价、不改动。
- `无法确认` 的段如实记为 `unconfirmed`，不并入完成或未完成；允许段内逐拍翻面，
  结局按「最后一次有效证据 + 退出原因」分账，同时保留逐拍序列供复算。

## 5. 离线验收指标

分母 = 换道段（`route.phase=merging` 的连续拍），不是拍数；跨道段的身份须先核验
（目标道全程不变、阶段连续），被污染的段不进指标表。

**样本独立性**：同一局内的多个换道段高度相关（共享同一套感知与参考系误差），
不得按段数直接当独立样本。结果先按局分别报告；跨局汇总只在按局分组之后给出，
样本量允许时用按局分组的区间或重采样，不用段的二项误差冒充证据强度。

| 指标 | 定义 | 口径要求 |
|---|---|---|
| 错误完成（主指标） | 判 `完成`、事后核验显示车未真正进入目标带 | 核验证据必须与判定证据**不同源**；核验本身也是估计，报告须写明来源与一致性，不得把单一来源当绝对真值 |
| 确认延迟 | 第一次「有效位置证据进带」到 `finish` 的拍数 | 只用有新鲜证据的段计算；无新鲜证据的段记「不可算」 |
| 超时率 | `merge_timeout` 段 / 全部段 | 与「完成」并列，不折算 |
| 重建率 | 段内发生 `epoch_reset`/`rebuild` 的段 / 全部段 | 重建后原段结束，重开新段 |
| 无法确认率 | 结局为 `unconfirmed` 的段 / 全部段 | 单列，不并入失败 |
| 证据年龄分布 | 位置项/速度项的观测年龄分位 | 按结局分账，不做全段池化 |
| 判定—核验一致性 | 同号 / 异号 / 一缺一有 | 三类分别给段数与占比 |

每段一行并附：trace 文件、产出代码版本（commit）、判定器版本、用到的列及其证据类与年龄。
探针不得读 pixel 级车道线作为横位真值（本目录 2026-10-27 追加已记：像素跟线被
车灯/护栏带偏，换算给出过 −2.84 道这类荒谬值），只能用与判定链不同源的横向估计。

**一致性与正确性分开**：「判定—核验一致性」只衡量两套估计是否打架，不衡量完成
判定是否正确。错误完成率只有在核验侧具备独立且有效的证据时才有解释价值；
两者不得互相推导（一致 ≠ 判对，不一致 ≠ 判错）。

## 6. 留痕与复算

- 原始 trace 不裁剪；判定器只读，不写 trace、不碰模型。
- 决策拍结论与事后核验标签**分列**保存，禁止互相覆盖或任何方向回流。
- 复算入口：给定 trace + commit + 判定器版本，任何人可复得同一张表；
  判定器输出必须带版本号，口径变更同时更新本文。

## 7. 已知问题（独立登记）

### G1 自车道被走廊判为走不下

- 现象：重建落点与现实所在道不一致（临时统计 27/39 次重建落到别道；未固化探针，复算前只作方向）。
- 影响：路线参考道被钉到一条不存在的道上，后续完成判定整段失真。
- 归属：走廊/重建，**不属本判定稿**；不得被机会换道主线的测试全绿掩盖。
- 处置边界：本稿只要求把重建结局、落点与实测横位三列入表，供独立立项时复算。

### G2 完成判据依赖过期观测

- 现象：路心读数保持拍占多数（临时统计约七成），完成拍多数建立在保持值上；
  速度项因此常是「保持差商 = 0」，等于速度门自动通过。
- 归属：**本稿 §3 正是它的验收对象**；本稿只判定，不修控制链。
- 处置顺序：先按本稿统计错误完成率与无法确认率，再决定是否改完成判据；
  改判据单独立项，不在只读阶段顺手改。

### G3 路心读数缺独立观测年龄

- 现象：只有 `dgeo_age`（深度证据年龄）与来源名；`memory`/`wall_occl` 的保持时长
  无法直接从 trace 读出。
- 影响：§1 的「几岁了」只能对新鲜拍给出精确答案，保持拍只能给下界。
- 归属：观测面缺口；补列属控制链之外的观测改动，本稿不实施。

| 预测不确定性 | 未建模 | 同上 | 校正后残差 vs 预测年龄 | 未知 |
| 错误完成率可接受上限 | 未定 | 同上 | 主指标 | 未知 |
| 确认延迟可接受上限 | 未定 | 同上 | 主指标 | 未知 |

以上各项在拿到实跑数据前一律保持「未知」，不写占位数值；标定完成后
数值与其标定依据一并落 ADR，本文只留指针。
