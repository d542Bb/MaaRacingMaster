# MoGe 单目点云 → 可行驶栅格：离线调查（2026-10-04）

> **问题**：speedrush 现役找边链（`depth_geo.reading_from_points`）在近场视锥、超车
> 挖洞、单侧/弯道场景下路缘经常不可测；但诊断显示**路面本身**（地面高度一致性）在
> 这些场景大多可见。问：把点云转成「可行驶栅格」是否成立——**看路是否只需要路面可见**。
>
> **范围**：只读离线调查，不改任何生产代码。所有数字来自
> [`probe_drivable_grid.py`](probe_drivable_grid.py) 的实际运行输出（
> `.workbuddy-ai/drivable_grid/stats.json`）。**实测事实**与**推断**分节标注。
>
> **一句话结论（实测）**：在**有有效深度点的格子**里，近场 85.8% / 远场 80.3% 被判
> 「可走」；不可走的其余部分是被墙体/路缘/车辆占据的格。挖洞格（挖掉全部证据）
> **0 例**误判为可走。**但**栅格并不稠密——近场 37.9% 的格未知（约一半是近场视锥
> 截断、一半是无深度点），远场 47.3% 未知（几乎全是无深度点）。

## 二、方法（口径，全部照抄现役实现，只 import 不改）

| 环节 | 口径 | 出处 |
|---|---|---|
| 证据包 → 全幅点云 | 336×598 fp16 点图 + valid + 归一化焦距 → 各通道 resize 到 1280×720 → invalid 置 nan；ego 掩码取资源文件、object 掩码 = `*_mask.npy` 减 ego | `probe_depth_equiv_441.assemble()` |
| 地面平面 | `depth_geo._fit_road_plane`（特征种子 + 走廊收敛，含 dig 挖除） | 直接调用 |
| 高出路面 hgt | `sgn·(Y−(aX+bZ+c))`，`sgn` 按 z=5m 处平面高度符号定翻转 | `reading_from_points` 同式 |
| BEV 栅格 | z 3~16m、x ±8m、0.25m 格（52×64） | 任务规定 |
| 可走容差 | \|hgt 中位\| ≤ 0.15m（= `depth_geo.PLANE_TOL`） | 项目既有阈值 |
| 单格「已知」下限 | 有效点（非挖洞）≥ 3 | 本探针设定（见局限） |

**三态判据**（每格取检测带内、非挖洞、落窗内点的 hgt **中位**）：

- **未知**：有效点（非挖洞）数 < 3（无点 / 点全被挖除）；
- **可走**：中位 \|hgt\| ≤ 0.15m；
- **不可走**：中位 hgt > 0.15m（显著高于地面，含天空/桥/墙）或 < −0.15m。

**关键补充量**：逐格标注是否落在相机视锥内（`|x| ≤ z·(W/2)/fx`）——近场视锥窄，
±8m 窗在近处远宽于画面，这部分「未知」属**几何必然**，不是「路看不见」。本报告把
未知拆成 **视锥内 / 视锥外** 两栏。

### 4.2 近场 vs 远场（核心判据）

- **「可见即可走」近场 85.8%、远场 80.3%**——有有效点的格里，八成以上判可走；
  其余不可走格是被墙/路缘/车辆占据（见代表帧图红区）。**近场不低于远场**，
  说明近场路面可见性一旦成立，可走判定同样可靠。
- **未知的成因两侧不同（关键）**：
  - **近场未知 46% 落在视锥内、54% 在视锥外**——视锥外那部分是 ±8m 窗在
    z<~6m 处宽于画面 FOV（z=3m 时半宽仅 ≈2.7m）造成的**几何必然**，不是「路看不见」。
  - **远场未知 100% 落在视锥内**——远场窗完全在画面里，未知即**真无深度点**
    （MoGe 无效 / 远处贴地平线涂抹），与 README「远场深度涂抹」结论一致。

### 4.3 金标帧：可走域 vs 真值车道

金标 = `depth_review/npy_moge/{000100,000340,000906}.npz`（全幅点云），标签 =
`gold_labels.csv` 左右缘线像素坐标。缘线像素沿线段取样 → 查该像素 Z → 米制 (z,x)。

| 帧 | 分层 | 金标 L 缘 z 跨度 / x | 金标 R 缘 z 跨度 / x | 近场 recall | 远场 recall | 近场 ΔR | 远场 ΔL / ΔR |
|---|---|---|---|---|---|---|---|
| 000100 | wall | 10.3~43.8m | 6.7~48.4m | n/a¹ | 68.3% | −0.55m | +2.11 / +1.07m |
| 000340 | wall | 8.6~53.8m / ≈−10m | 5.2~30.8m / ≈+6m | 75.1% | 59.3% | +0.10m | +2.42 / +1.87m |
| 000906 | curve_cont | 9.7~33.2m / ≈−10m | 5.2~24.5m / ≈+6m | n/a¹ | 64.1% | +0.94m | +2.63 / +1.90m |

¹ 金标**左缘实测在 x≈−10m、落在 ±8m 窗之外**（000100 L 跨 z 10.3m 起、000906 L 9.7m 起），
近场带（3~9m）该侧无金标样本 → 近场左偏差不可比（记 n/a）。**ΔL≈+2.1~2.6m 是窗截断
的必然结果，不是几何误差**（可走域最左只能到 −7.875m）。

- **ΔR（可走域右边界 − 金标右缘）近场 +0.10~+0.94m、远场 +1.07~+1.90m**——金标右缘
  （wall/kerb，x≈+6m）在窗内，这是**可比**的物理偏差：可走域右边界比真值缘**外扩**
  1~2m。
- **corridor recall（金标走廊∩窗 被可走覆盖的比例）59.3~75.1%**：六到七成半。
  其余部分是走廊内的未知（无深度点）与少量不可走。

### 4.4 挖洞检查

被挖洞（ego 矩形 / YOLO 物体框）的格，按挖后证据分两类：

| 类别 | 格数 | 占比 | 三态 |
|---|---|---|---|
| 挖后**无证据**（剩余有效点 < 3） | 97308 | 86% | **全部未知；误判可走 = 0** |
| 挖后**仍有证据**（边界格，部分重叠） | 16146 | 14% | 可走 14785 / 不可走 1361 / 未知 0 |

**实测**：证据被挖空的格 **0 例**落为可走——挖洞语义（车从点云消失 → 该处不该被
判「可走」）在「挖空」这一档严格成立。挖后仍有证据的 14785 格是**检测框边界上的
部分重叠格**（0.25m 格内车只盖住一部分、路面点尚存），按现行「带内点中位」判据判可走。

## 五、推断（非实测，需进一步验证）

1. **可行驶栅格对「看路」是成立的**：路面可见处 80~86% 判可走，且**近场不劣于远场**；
   现有找边链的近场视锥/挖洞失效，在栅格口径下主要转化为**未知**而非**误判可走**——
   这支持「路面可见性是可走性的充分性主要来源」这一假设。
2. **栅格不是稠密可行驶图**：可走占带仅 42~53%，远场近半未知。若下游要「整条路都能
   走」，远场无深度点是硬约束（与「远场前瞻线不可测」的既有结论同源）。
3. **超车桶远场未知最高（62.2%）**：与「超车挖洞 + 车体遮挡远场」一致——物体框把
   远场车区挖空后，远场本已稀疏的深度更稀。
4. **弯道桶「可见即可走」最高（近 89.6%/远 86.3%）**：弯道帧墙体常出画，带内多为纯
   路面，故可走占比高、不可走少——与「弯道不是找边的几何难点、是直线假设的难点」一致。

## 六、局限与坑（自认）

1. **近场视锥截断污染了「可走占带」**：±8m 窗在 z<6m 宽于 FOV，`drivable_frac`
   被系统性拉低。判读应以 **「可见即可走」** 为主，`drivable_frac` 为辅。
2. **金标对照受窗截断主导**：3 帧金标缘线（wall/kerb）在 x≈±10m、多半出窗，只有
   右缘可比；corridor recall 也被窗裁过。结论只作方向性参考。
3. **单格「已知」下限 = 3 点、容差 = 0.15m 是本探针设定**，非产线定值；改这两项会
   改变三态占比（未做敏感性扫描）。
4. **桥/空中结构**：判据把「中位 hgt > 0.15m」一律记不可走，桥下可通行区会被记不可走
   （未单独处理头顶结构）——本批 3 会话桥帧少，未在图上暴露。
5. **部分重叠挖洞格判可走**（4.4 的 14785）：若下游要求「可走格不得与任何检测框重叠」，
   需在消费侧加更严的挖除语义（本探针如实报出，未替下游裁定）。
6. **场景标签来自 trace，不是视觉真值**：雨天/晴天按会话归属（同会话天气恒定）；
   弯道/超车按 trace 列。帧选取见第三节说明。
