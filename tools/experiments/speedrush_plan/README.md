# speedrush_plan —— 横向轨迹规划标定与回放

status: active

motion_plan 架构（场景快照 → 时空横向轨迹评估 → 预览跟踪）的离线实验区。

## fit_plant.py

从控制 trace 拟合横向 plant 参数 `(a_lat_gain, tau_align_s, v_lat_max, tau_steer_s)`。

```bash
.venv/Scripts/python.exe tools/experiments/speedrush_plan/fit_plant.py \
    --trace <trace.jsonl> [--trace ...] [--out report.json]
```

口径：

- 似然 = 一步转移 + 生产同款 α-β 观测模型；修正拍不剔除。
- 留出验证按整段 trace 留一；参数 CI 用 Jacobian 近似（仅作退化检查）。
- `sigma_ego(t)` 由多步开环残差按 horizon 拟合，保守含路心观测噪声。
- 缺 `steer_raw` 列的旧 trace 只能拟合三个参数，`tau_steer` 不可辨识，
  `calibrated=false`；需要新录一局带 `steer_raw` 的 trace 才能解锁。
- `calibrated=false` 时 `motion.mode=live` 必须 fail-loud（影子/离线不受限）。

## replay_plan.py

读带 `scene/plan` 列的控制 trace，按录制顺序回放 `plan_motion`（gate 同构），
输出确定性对齐率、`plan.valid` 覆盖率、层分布、预览抖动与单拍 P99。

```bash
.venv/Scripts/python.exe tools/experiments/speedrush_plan/replay_plan.py \
    <trace.jsonl> [--out summary.json]
```

## 半程反打候选（2026-10-30，画龙实验）

**改动**：`plan_motion` 的候选从「恒杆 2s + 当前杆值」扩为「恒杆 2s + 半程反打
（前 1s 打 u、后 1s 打 −u）+ 当前杆值的反打」。恒杆开环在接近目标时预测里
没有“停下”，计划只能靠下一拍换杆追，选出的大杆值天然过冲、晚反打
（`docs/plan/lateral_behavior_contract.md` 阶段 1.5）。反打候选只给 |u|≥0.2
的杆值；当前杆值的反打恒存在，候选数固定 21（闸门存续项下标不随拍变）。

**离线回放**（`probe_reverse_candidates.py`，同批拍分别喂两种候选集、各自
gate；20261030 两局）：

| 指标 | 旧候选 | 新候选 |
| --- | --- | --- |
| 大误差反向打杆 | 25.0% / 36.9% | 23.5% / 31.4% |
| L4 保住段“朝速度反打”占比 | 63.2% / 56.1% | 71.1% / 57.1% |
| L4 偏移拍预测末端偏差（道） | 0.94 / 0.90 | 0.64 / 0.66 |
| L4 偏移拍预测峰值（道） | 1.13 / 1.18 | 0.98 / 1.05 |
| 杆值换向/分 | 45.6 / 31.0 | 46.2 / 31.7 |
| 单拍耗时 p50 / p99 (ms) | 0.41 / 0.88 | 0.70 / 1.37 |

方向符合预期；代价是计划单拍 +0.3ms p50、+0.5ms p99（控制链 p50 由约 2.3ms
升到约 2.6ms）。**离线只验证预测面**：ego 状态用录制值、开环重放，闭环是否
真的少画龙要看真机 A/B。

**观测量**（跑完对照）：横穿路中心次数、横位摆幅、车身压过走廊边线的拍数、
大误差反向打杆占比、计划失效、得分速度。

```bash

    <trace.jsonl> [--out out.json]
```

## 意图抖动：闸门确认 + 币不居中（2026-10-30 下午）

人工局 `20261030_114825` 的逐拍证据：计划杆值中位 3 拍一段、48% 的段
只活 1–2 拍；计划层里擦边层 36 段有 25 段只活 1 拍、金币段中位 2 拍。
根因是计划闸门的「价值差 > immediate(100) 立即切」：擦边 120 / 空中金币
120 / 奖励车 240 都过线，单帧检测闪断就拽杆，下一拍消失再拽回。

改动两处：

1. **闸门**：立即切换只给安全类（最优候选碰撞代价更低，或现任得分目标
   已失去、最优回中）；新出现的得分机会改走 dwell(0.2s) 确认。
2. **币目标**：`_coin_aim`——车有半宽，币心落在车身带（0.27 道）内就
   保持原线，带外只走到带边，不再对币心；换道请求按带边算。收集判据
   （计划层 0.35 道）比车身带宽，压在带边仍能吃到。

离线（闸门按 trace 逐拍恢复、同批拍）：

| 指标 | 改前 | 改后 |
| --- | --- | --- |
| 杆值段数（人工 87s） | 332 | 312 |
| 段长中位（拍） | 2 | 3 |
| 1–2 拍短段占比 | 51.5% | 46.5% |
| 杆值换向/分（人工） | 54.9 | 50.7 |
| 杆值段数（自动 613s） | 1,629 | 1,565 |
| 原始选择目标跳变（人工） | 158 | 144（币带内保持原线） |

幅度都不大：dwell 只有 0.2s，持续 3–4 拍的机会照样会切；真正的结构缺口
是「近到远目标候选链」没有实现——选择层每拍只挑一个目标，没有跨帧锁定的
链，层一变目标就跟着跳。链条是下一步的大件，本轮先不动。
