# status_orb —— 底栏状态球的形态预览

status: active

## 目标

GUI 底栏左侧的指示灯目前是 8px 静态圆点（就绪绿 / 运行中绿+扩散环 / 停止中黄 / 错误红）。本实验把
它换成一个拟人化的球体角色，验证「表情能不能承担状态语义」以及「多大尺寸才看得出表情」。

本目录是前端设计评审用的静态形态预览，不接生产数据，不参与构建。

## 打开

浏览器打开 `preview.html`。页面包含：

- **放大检视**：四种状态并排，96px，用来看造型细节。
- **真实尺寸**：按 GUI 底栏 44px 高、白底、上边框复刻，旁边是原 8px 圆点作对比，下方可切换状态与拖动直径（16–30px）。
- 鼠标移到球附近（100px 内）才激活跟随；离开后眼睛自己四处看，偶尔转回来；静置 2–6 秒眨一次眼。

## 口径

- **参考来源**：造型比例与行为参数（眼宽 / 眼高 / 眼中心距、眨眼时序、指针静止后自行漂移）
  参考 21st.dev 上的公开组件 live-orb，按用户确认可直接借鉴。
- **实现方式**：该项目无 React / Tailwind / TypeScript 技术栈，前端是 WebView2 直读的纯
  HTML + CSS + JS。因此不复用参考组件的代码（其实现是 WebGL 片元着色器 + React 封装），
  而以原生 SVG 重画，行为逻辑用原生 JS 重写。只有比例与参数是照搬的。
- **扁平化**：球体是单色相的径向填充（中心到边缘四档衰减，没有高光、投影），
  眼睛与表情都是纯白线条，不描边。
- **3D 转动**：眼睛不是贴在圆片上的两个矩形，而是球面上的两段弧。每帧把球面基向量与
  眼睛中心一起旋转，再沿球面取一串点投影到屏幕，连成弧线当作胶囊的脊——所以眼睛本身是
  弯的，会随球面起伏；转到侧面会变短变窄，转到球边会被球轮廓切掉。都是投影的自然结果，
  不是逐角度手调的。数学同球面着色器的做法，只是把逐像素计算换成了逐点采样，不需要 WebGL。
- **状态视觉**：就绪是淡绿光晕（球体略微透明 + 边缘按球径缩放地揉软，没有描边，边缘自然
  消失）；运行中是实心淡绿（撤掉模糊、拉满不透明）；停止中是实心琥珀；错误是实心红。
  状态切换只做填充、透明度、颜色的过渡，不做任何位移或缩放——球体始终是同一颗正圆，
  停止中也不再压扁。
- **眼睛与表情**：白色线条，无描边。线条不是矩形，而是沿球面采点连成的弧（路径只提供脊线，
  粗细即眼宽）。四种状态共用同一套球面几何，只换「沿哪个方向张开」：
  就绪 / 运行是竖弧（睁眼），停止中是沿水平方向的两条短线（`--`），错误是两条 ±45° 斜线
  交叉（`××`）。所以表情同样会随球面转动、变窄、被球轮廓裁切。
  三个表情的笔画重量要对齐：`--` 与正常眼等宽，`××` 取 0.8 倍——交叉线等宽时
  交点会糊成一个实心块，这是唯一必须让步的地方。长度上 `--` 要把两端圆头算进去，
  否则左右两条会接成一条「—」。
- **比例补偿**：参考组件的原始比例是给 280px 的球设计的（眼宽仅占球径 5.4%），照搬到 18px
  只有 1px 宽、会糊成半透明线。本实现宽度按 1.8 倍补偿，高度等比放大，细长比例不变。
- **跟随只在近处激活**：指针进入球心 100px 才跟随，离开放宽到 120px（迟滞，避免边界抖动）。
  远处的鼠标不激活跟随，球自己四处看——底栏角落的球不该被半个屏幕外的光标牵走。
- **球体不呼吸**：「活着」由眼睛承担（跟随、漂移、眨眼），球体本身不做缩放。
- **动效降级**：系统开启「减弱动效」时停掉漂移、眨眼与回声环，视线固定在默认
  位置；指针跟随与颜色过渡保留（前者由用户触发，后者不产生位移）。

## 待定

- 当前默认值（已按评审确定）：直径 18px、眼宽 1.8×、眼高 0.8×。
- 表情尺寸：`--` 与 `××` 的长度 / 粗细由 `orb.js` 顶部四个常量控制
  （`DASH_LENGTH_GAIN` / `DASH_WIDTH_GAIN` / `CROSS_LENGTH_GAIN` / `CROSS_WIDTH_GAIN`），
  都是相对眼宽、眼高的倍率，改球径不用动它们。
- 运行态流转的强度：`orb.css` 里运行态的 `--orb-c-*` 四档饱和度差决定对比，`orb.js` 的
  `applyFlow` 决定游走轨迹。
- 是否上生产：上生产时 `orb.js` / `orb.css` 移入
  `apps/MaaRacingMaster.Shell/frontend/`，`index.html` 换容器骨架，`js/run.js` 的 `setStatus`
  改为调用 `StatusOrb`；PEEP 悬浮窗（`peep.html`）的状态点暂不动，两处样式并存。
