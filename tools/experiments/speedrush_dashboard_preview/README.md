# speedrush_dashboard_preview —— 极速狂飙回合战绩看板形态预览

status: active

## 目标

确认回合战绩看板在 420px 数据页右栏里的信息密度与列表行为。预览只做形态评审。

## 内容

- 统计卡 4 项：今日回合、今日胜场、总回合数、总胜场。
- 回合行：回合开始时间、模式、自己分数（蓝）/对手分数（红）、胜负与分差；未完成的回合带「未完成」标记。
- 列表按日期分组，组头显示「今日」或「MM-DD」，组内只显示时间；每次展示 5 条，滚到底自动续 5 条，滚动条隐藏。
- 统计计程序控制局（深度几何、全程直行、宏回放）；人工录制与宏录制不计入。
- 底部只留一句口径：胜负按终盘比分判断。

## 数据

`payload.js` 的 `data / no_opponent / phase1_only` 来自 2026-11-05 本机两局实测（4 个驾驶阶段）：

- 回合 1：阶段 1 得分 2,579、阶段 2 末值 5,693；对手末值 7,858。
- 回合 2：阶段 1 得分 2,233、阶段 2 末值 6,899；对手末值 8,929。

`many` 的 12 行是分页演示用的合成数据，不是实测。fixture 不含本机路径与会话 token。

## 打开

双击 `preview.html`（`payload.js` 用脚本标签加载，`file://` 可用）。顶部切换：

- 有数据、空态、缺对手分、仅阶段 1、读取失败、长列表。

## 退役

用户确认形态、正式看板渲染出同一形态后，本目录整体删除；结论进 `plugins/speedrush/CODE_WIKI.md`，证据指向 commit。不要把本目录路径写进正式知识、生产代码或测试。
