## 1. 任务与约束

**目标**：从游戏录屏（1280×720 帧）恢复道路平面上的车辆位置（车道坐标），
用于下游自动化决策（需要车道号级精度，横向 ±0.25 车道）。

**已知事实**（游戏侧权威 + 实测确立）：

- 相机：自车后方固定追车相机；**自车钉在画面中央**（u_ego ≈ 640，观测事实）；
  俯仰/高度未知且不可配置。
- 道路：4 车道；3 条白色虚线分隔 + 2 条实线边线；自车在第 3 车道中央
  ⇒ **夹自车的两条虚线间距恰为 1 个车道宽**。
- 场景：直道与弯道交替；AI 目标车不变道、不转向（横向真值恒定，
  但不保证严格在车道中心——见 §5）。

**模型**（针孔 + 地平面假设）：

```
d = v − y_h          （d ∝ 1/深度）
X = A_x · (u − VPx) / d     （X 单位：车道宽）
Z = A_z / d
```

未知数四个：VPx（消失点横坐标）、y_h（地平线行）、A_x（横向尺度，
= 每车道在参考深度处的像素宽换算）、A_z（纵向尺度）。

**工程纪律**（本项目实验守则）：判据先写死后开工；禁止为过闸调参；
「跨场稳定」只算重复性证据、不算正确性证据；A_x 只允许由几何口径重算，
禁止由下游回归反调。

## 3. 开放核心问题：两种「车道宽度」测量稳定相差 13%

对同一个物理量——**夹车两虚线在参考行 v=650 的横向间距（px）**——两条
内部测量路径给出稳定互斥的答案：

| 口径 | 定义 | 结果 |
|---|---|---|
| **P（现行）** | 每条 ≥100px 纵向跨度的线段用自身斜率外推到 v=650 得截距 → 截距按 gap 40px 聚类 → 取夹住 VPx 的**左右最近簇中位之差** | **581px**，八场 CV≈1.8%（极稳定） |
| **F** | 线段按截距聚成「族」（gap 60px、≥4 段 = 同一物理线），族内**全部端点拟合直线** u=αv+β → 左右两族拟合线在 v=650 的间距 | 正确配对的帧给 **666~668px** |

第三个独立观测支持 F：用口径 P 的 A_x（=327/581=0.563）计算框内夹车虚线
间距，八场得到 s_med = 1.027~1.168、中位 ≈1.09、**方向全部 >1**：

```
s_med = A_x(P) / A_x(真) ⇒ A_x(真) ≈ A_x(P)/1.09 ≈ 0.517 ↔ 632px
而 668/581 = 1.15，与 s_med 定量吻合（1.09~1.14 区间内）
```

且 668px 与最朴素的直接证据吻合：人工核对过的帧里夹车虚线在 v=650
实测位于 u≈312 与 u≈980（间距 668px，且关于画面中心 640 对称）。

### 已排除的解释层（审计实验，全部不动标定参数）

1. **针孔/外推层**：Δx(v)（两拟合线间距）在 v=550~700 的扫描严格线性，
   Δx(v)/Δx(650) 八场逐位一致 = (v−323)/327；两拟合线**交点恒在
   (VPx±3px, y_h±4px)**（33 帧）。⇒ 用 v=650 做统一参考行外推无罪，
   VP 与虚线几何自洽。
2. **检测/聚类层**：同一 d 分箱内「实测点 u 中位差」vs「拟合线差」=
   1.009 (d<250) / 0.978 (d<400)，±2%。⇒ 分歧不来自 Canny/Hough 或聚类。
3. **远距噪声**：s_med 对 d 下限梯度（12/60/120px）无响应。⇒ 不是远端
   碎段的 1/d 放大噪声尾巴。
4. **AI 车辆轨迹**：其回归 α 与 9% 不同源（后述 §5，AI 仪器另有质量问题）。

### 口径 P 的缺陷机制（已定位）

「最近簇」量到的是**虚线内缘/次近结构**而非道中心距：同一条虚线的各段
截距因段斜率噪声散布（gap 40px 聚类把它打散成多个簇），vpx 两侧的
「最近簇」于是系统性偏向画面中心 ⇒ lane_px 稳定偏小 13%。
**教训（本轮最有价值的一条）**：同一方法的系统偏差同样跨场稳定——
CV 1.8% 的「稳定」是假干净；不同几何路径的交叉验证（截距外推 vs
拟合线交点）才暴露了它。

## 4. 失败的修复尝试：「逐帧配对两线」方法类整体证伪

想用口径 F 替换 P，四种配对规则全部失败：

| 版本 | 规则 | 结果 | 死因 |
|---|---|---|---|
| v2 | vpx 两侧最近族（拟合线） | 815px | 夹车虚线单边遮挡时退化到边线 |
| v3 | gap 120 防碎裂 + 对称检验 \|u_l+u_r−1280\|<150 | 477/579/725 乱跳 | 放宽段数门槛后护栏伪对恰好「对称」 |
| v4 | v2 族定义 + 对称检验 | 7/8 场 n=0 | 真夹车对常单边缺失，凑不齐对称对 |

**根因是物理性的**：夹车两虚线在比赛帧大多**单边可见**（自车车身遮挡
近段 + 虚线本身有间隔，可见碎段少时族被截距散布打散）。任何「逐帧选
两条线」的规则，在缺失 + 伪目标并存时要么选错要么饿死。

目前唯一可靠的做法是人工挑出配对正确的帧（668px 锚），无法自动化。

## 5. 次要开放问题（AI 轨迹仪器）

AI 车横向真值恒定（不变道不转向），本应是最好的绝对验证仪器，但：

- 有 tracker 换车污染（叠图实锤：目标框从被跟车跳到邻道红车）；
- 有稳定道内偏移（目标车长期在车道中心偏左 ~0.4 道行驶）——
  「不变道」≠「在道中心」，推翻了「轨位置 = 整数车道」的 round 归属；
- 远距观测 X 外推爆炸（d<15px 时噪声 ±0.2 道）。

已实现「有界道内偏移」模型 X_i = bias + α·k_i + δ_i（|δ|≤0.35、|k|≤3、
bias 全局网格搜索），但输入质量仍不足以支撑格假设检验（8 场 7 场不过，
失败 δ 达 1.7~4.1 道 = 假轨）。当前定位：AI 轨只作辅助诊断，
正式尺度结论由道路几何给出。

## 6. 想请外部专家判断的具体问题

1. **§3/§4 的正解是什么？** 在「车道线族常单边缺失 + 护栏/边线伪目标 +
   虚线间隔碎裂」条件下，可靠测量两虚线间距（或等价地，车道像素宽）的
   成熟做法是什么？我们的候选提案是**全局格阵 RANSAC**：跨帧汇集所有族
   的拟合线 u@650 位置，真车道线落在 {±0.5,±1.5,±2.5}·L+φ 格上，
   采两点定 (L,φ) 数内点取最优——护栏自然离格、逐帧缺失由跨帧汇集补偿。
   这个方向对吗？车道线检测文献里有没有现成方案？
2. **有没有完全绕开「两线间距」的 A_x 来源？** 例如：单条虚线族的拟合线
   斜率 α 直接给 X 尺度（α = Δu/Δd，对夹车虚线 |α| 与 0.5 车道对应）？
   或利用自车钉画面中央 + 虚线对称性做单线测量？
3. **下游只需要车道号**（X 量化到整数格）。A_x 的 13% 误差是否可以用
   「格阵自校准」吸收——即不测绝对宽度，只保证 X mod L 的格相位稳定？
   这种弱化目标下最小需要修到什么程度？
4. 固定追车相机场景，有无更直接的标定途径我们没想到
   （如利用画面中已知尺寸的静态元素）？
