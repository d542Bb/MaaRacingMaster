## 为什么现在做这个

trick 实验的撤回证明：现有像素量（`|cx−锚|`）测不了"贴近"——透视收敛把它污染成假信号
（三证见 trick README ②）。缺的不是深度模型，是**一条像素→地面的标定映射**。
标定到手后按序解锁：① §7#2"贴车触发"用**车道单位**重测（含"极限组偏右 18/22"线索的真伪）；
② 阶段 B 感知规格定案（框 → (车道号, 横向偏移, 纵向距离, 相对速度)）；③ 收益模型的状态空间。

## 采纳的方法主干（外部调查 §1~§20，与本项目失败分析互证）

- **标定源只用静态几何**：车道线/边线/护栏的候选线段（Canny + HoughLinesP）→
  **VP 是统计量不是两线交点**（成簇投票 + RANSAC）→ 得 (VPx, y_h)。
  动态量（目标轨迹、HUD 速度）**只进验收、不进拟合**——这正式定性了 planning 实验
  `y_h=315` 的失败：运动学与投影参数耦合，车的相对速度伪装成透视参数。
- **参数模型**：`(y_h, H, f)` 三自由度（cx 固定 640——本项目已实测 82% 帧 |自车偏移|≤40px，
  报告"待实测"清单里这一条可划掉）；工程上等价于 `(y_h, A_x, A_z)`。
  映射 `X = A_x·(u−cx)/(y_h−v)`、`Z = A_z/(y_h−v)`，**接地点用框底边 v**（本项目口径已如此）。
- **平直段选数据**：标定只吃平直路段帧；弯道/坡道/跳台用 `flat_confidence` 旁路
  （VP 时间稳定性 + IPM 后车道宽随距漂移），**不做坡度估计**。
- **排除清单**（与 vision README 独立同结论）：单目深度网络、SLAM、学习式车道回归、
  运动学拟合当标定源——全部排除，理由见外部报告 §36。

## 三处更正（报告的现实道路先验在本作不成立）

1. **车道宽不是已知米数**。报告的主尺度观测（"车道宽 3.5 m"）是真实道路先验；本游戏的
   车道宽**未知**，且"游戏渲染参数"不可得（不碰引擎内部）。→ **尺度两级化**：
   **横向以"车道宽"为单位**（判"贴近"够用——判据本来就是"半个车道"量级）；
   **纵向用 HUD 米速钉 f·H**（里程 1 分/米 `[三方来源·待复核]` → 实测自车 ≈42 m/s）。
   报告的"第三选择（HUD 位移）"对我们是**唯一选择**，"第一选择（游戏镜头参数）"不可用。
2. **Gate 3 的静止目标假设不成立**。街车在动，超车定义即 ego 更快。→ 纵向米制校验改用
   **车道虚线以自车速度回流**（静态纹理的 dZ/dt 应 ≈ HUD 自车速度）；目标轨迹的 dZ/dt
   只查量级自洽（相对接近速度 ∈ (0, v_ego]）。
3. **y_h 有强先验区间**。路面带实测起于 y≈180、最远检出 y≈213 贴地平线（vision 实验），
   故 `y_h ∈ [180, 260]` 作拟合边界——失败解 315 本就被此区间排除，报告示例值 308 不可照抄。

另记：里程"1 分/米"本身是 `[三方来源·待复核]`——所有米制结论（含 Gate 3）带此不确定性，
车道单位结论不受影响。

## 验收闸门（先写死后开工，任一红即停、按 §38 归因，不加码换模型）

| 闸门 | 判据 | 红时的归因方向 |
|---|---|---|
| **−1 合成自检** | 用已知 (cx, y_h, A_x, A_z) 生成投影线，标定器反推须回到 ±ε | 数学实现错，不碰真帧 |
| **0 VP 稳定** | 平直段逐帧 VP：VPx 638±?、y_h 带内且帧间稳；**叠图目视**（线簇真的射向该点） | 线段族不纯（护栏/对向/建筑吸走） |
| **1 不变道不变性** | 未变道目标的 X_t 漂移中位 < 0.25 车道宽 | y_h 错 / pitch 漂 / 接地点错 |
| **2 车道号阶跃** | X 直方图多峰、峰距 ≈ 1 车道宽 | 横向尺度错 |
| **3 纵向一致** | 虚线回流速度 ≈ HUD 自车速度（±15%）；目标接近速度量级自洽 | f·H 错 / 平面假设失效 |
| **4 跨会话窄带** | ≥3 场独立标定，参数 CV < 5% | 标定器不稳，**不得用下游精度掩盖** |
| **留出** | 70% 线证据拟合、30% 只验收 | 拟合自洽 ≠ 解释世界 |
