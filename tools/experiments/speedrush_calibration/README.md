## 为什么现在做这个

trick 实验的撤回证明：现有像素量（`|cx−锚|`）测不了"贴近"——透视收敛把它污染成假信号
（三证见 trick README ②）。缺的不是深度模型，是**一条像素→地面的标定映射**。
标定到手后按序解锁：① §7#2"贴车触发"用**车道单位**重测（含"极限组偏右 18/22"线索的真伪）；
② 阶段 B 感知规格定案（框 → (车道号, 横向偏移, 纵向距离, 相对速度)）；③ 收益模型的状态空间。

## 采纳的方法主干（外部调查 §1~§20，与本项目失败分析互证）

- **标定源只用静态几何**：车道线/边线/护栏的候选线段（Canny + HoughLinesP）→
  **VP 是统计量不是两线交点**（成簇投票 + RANSAC）→ 得 (VPx, y_h)。
  动态量（目标轨迹、HUD 速度）**只进验收、不进拟合**——这正式定性了 planning 实验
  `y_h=315` 的失败：运动学与投影参数耦合，车的相对速度伪装成透视参数。
- **参数模型**：`(y_h, H, f)` 三自由度（cx 固定 640——本项目已实测 82% 帧 |自车偏移|≤40px，
  报告"待实测"清单里这一条可划掉）；工程上等价于 `(y_h, A_x, A_z)`。
  映射 `X = A_x·(u−cx)/(y_h−v)`、`Z = A_z/(y_h−v)`，**接地点用框底边 v**（本项目口径已如此）。
- **平直段选数据**：标定只吃平直路段帧；弯道/坡道/跳台用 `flat_confidence` 旁路
  （VP 时间稳定性 + IPM 后车道宽随距漂移），**不做坡度估计**。
- **排除清单**（与 vision README 独立同结论）：单目深度网络、SLAM、学习式车道回归、
  运动学拟合当标定源——全部排除，理由见外部报告 §36。

## 三处更正（报告的现实道路先验在本作不成立）

1. **车道宽不是已知米数**。报告的主尺度观测（"车道宽 3.5 m"）是真实道路先验；本游戏的
   车道宽**未知**，且"游戏渲染参数"不可得（不碰引擎内部）。→ **尺度两级化**：
   **横向以"车道宽"为单位**（判"贴近"够用——判据本来就是"半个车道"量级）；
   **纵向用 HUD 米速钉 f·H**（里程 1 分/米 `[三方来源·待复核]` → 实测自车 ≈42 m/s）。
   报告的"第三选择（HUD 位移）"对我们是**唯一选择**，"第一选择（游戏镜头参数）"不可用。
2. **Gate 3 的静止目标假设不成立**。街车在动，超车定义即 ego 更快。→ 纵向米制校验改用
   **车道虚线以自车速度回流**（静态纹理的 dZ/dt 应 ≈ HUD 自车速度）；目标轨迹的 dZ/dt
   只查量级自洽（相对接近速度 ∈ (0, v_ego]）。
3. **y_h 有强先验区间**。路面带实测起于 y≈180、最远检出 y≈213 贴地平线（vision 实验），
   故 `y_h ∈ [180, 260]` 作拟合边界——失败解 315 本就被此区间排除，报告示例值 308 不可照抄。
   **⚠ Gate 0 实测与之冲突（2026-09-19，待维护者裁定）**：三场 demo 无带交点云
   （MAD 15~30）与逐帧 VP 一致给出 **y_h ≈ 324~335**；该带推断链「最远检出车底 =
   最远可见路面」被证伪（检出器最远车底受探测范围限制，且 213 处可有无车远路）。
   先验带对真帧是错置，Gate 0 探针已改用宽诊断带 [150,420] 出数，修订待确认。
   连带疑点：实测 324 与 planning 实验的「失败解 315」接近，该失败归因（运动学耦合）
   是否成立需重审——不影响 trick 撤回的三证（透视收敛假象），只影响 planning 侧叙述。

另记：里程"1 分/米"本身是 `[三方来源·待复核]`——所有米制结论（含 Gate 3）带此不确定性，
车道单位结论不受影响。

## 验收闸门（先写死后开工，任一红即停、按 §38 归因，不加码换模型）

| 闸门 | 判据 | 红时的归因方向 |
|---|---|---|
| **−1 合成自检** | 用已知 (cx, y_h, A_x, A_z) 生成投影线，标定器反推须回到 ±ε。**VPx/y_h 的 ε 实施时定为 z-score（误差 ÷ 估计器自报 σ ≤3）而非绝对 px**——原「±2px」拍在 σ≈2px 的噪声底上，判据错置（合成下 σ 已知准，只有 z 才验数学自洽；绝对精度归 Gate 4 跨场 CV）。A_x ±5%/8%、A_z ±8%、留出 d/σ_d ≤1.5 不变 | 数学实现错，不碰真帧 |
| **0 VP 稳定** | 平直段逐帧 VP：VPx 638±?、y_h 带内且帧间稳；**叠图目视**（线簇真的射向该点） | 线段族不纯（护栏/对向/建筑吸走） |
| **1 不变道不变性** | 未变道目标的 X_t 漂移中位 < 0.25 车道宽 | y_h 错 / pitch 漂 / 接地点错 |
| **2 车道号阶跃** | X 直方图多峰、峰距 ≈ 1 车道宽 | 横向尺度错 |
| **3 纵向一致** | 虚线回流速度 ≈ HUD 自车速度（±15%）；目标接近速度量级自洽 | f·H 错 / 平面假设失效 |
| **4 跨会话窄带** | ≥3 场独立标定，参数 CV < 5% | 标定器不稳，**不得用下游精度掩盖** |
| **留出** | 70% 线证据拟合、30% 只验收 | 拟合自洽 ≠ 解释世界 |

### 闸门实施记录

- **−1 合成自检：绿**（`2163370`）。20 训练 + 24 未见种子全绿，报告
  `%TEMP%/sr_calib/gate_minus1.json`。VPx/y_h 判据定为 z-score（≤3），A_x 双路径
  max 误差 ≤1.3%、A_z ≤4.2%、留出 d/σ_d ≤0.8。
- **0 VP 稳定：分级筛帧 v2 + 留出验证（叠图再目视）**。
  - 首轮单帧自洽口径（sig≤5+内点≥12）：维护者目视约 30% 帧标定明显错误
    （比赛进行中帧 VPx 466/707/735、y_h 389~395）——候选线少而短时 σ_d 容差
    「来者不拒」，凑出自洽但错误的交点；自洽口径只验自洽、不验正确。
  - v1 修复用 y_h 众数当入场券，被维护者指认为**循环筛选**（用结果定义有效帧）
    且 70~80% 淘汰率的判除依据未证明独立于结果——重构为 v2 分级判据：
    **S1 证据充分性**（候选线 ≥8、长线 |Δv|≥150 ≥2、近端截距簇 ≥3——纯检测统计）
    → **S2 共点性**（强内点 σ_d≤12px ≥3、其中位标准化残差 ≤4——几何前提，
    与共点在哪儿无关）→ **S3 比赛态**（score OCR 覆盖处生效，辅助）
    → **S4 一致性检查**（y_h 距基准 ≤25 + 滑窗 |dx|≤12、|dy|≤8——**只做检查
    不做门票**，基准来自留出集）。S1/S2 阈值先验固定；v2 首轮过紧
    （截距簇 4 忽略虚线空档、zmed 2.5 超出真帧噪声）误杀正常帧，回调至
    「挡垃圾」本意（每条阈值依据见脚本注释），回调依据是 rejected 抽检

  - **被拒帧随机抽检**（每场 12 张带淘汰原因标注，`%TEMP%/sr_calib/rejected_*.png`）

## 实施顺序

1. ✅ `probe_ground_calib.py`：Gate −1 合成自检——标定器本体（VP RANSAC+IRLS /
   A_x 端点逆方差聚类+自车锚定晶格 / A_z 虚线回流网格 LS）已立，
   判据对 20 训练种子 + 24 未见种子全绿（换段复验防种子过拟合）。
   实现期三处关键定论（详见脚本 docstring）：① A_x 取样必须用**端点位置**
   s=(u−VPx)/(v−y_h) 而非斜率——同批数据精度高 20 倍，且斜率口径下夹车虚线锚对不可分辨；
   ② 尺度简并（g vs g/2 晶格同解释整格数据）在纯几何内不可分，破它的外部信息是
   **自车居中 ⇒ 夹车道宽=1 车道**（RULES §4 权威 + 实测锚），据此锚定半整格晶格；
   ③ 合成场景结构须按 RULES §4（自车在第 3 道、虚线在 ±0.5 道），首轮误把分隔线画在
   车正中央，给简并留了温床。
2. ✅ `probe_gate0_vp.py`：Gate 0 真帧逐帧 VP——v2 分级筛帧（S1 证据→S2 共点→
   S3 比赛态→S4 一致性检查）+ 被拒帧抽检 + 留出验证，见「闸门实施记录」；
   叠图与 rejected 抽检待维护者复核。
3. 车道宽序列 (v_j, Δu_j) → A_x（RANSAC/Huber）；虚线回流 + HUD 速度 → A_z。
   （−1 期 A_x/A_z 估计器已是 Gate 0~3 复用本体，此步改为喂真帧证据池。）
4. Gate 1~4 + 留出，出 `report.json`。
5. 全绿 → 回 trick：车道单位重跑"贴近分离"（含右偏线索）；任一红 → 停，按归因列报告。
