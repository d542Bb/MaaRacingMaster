## 4. 难题

1. **线位机械化**（O3 三破点）——当前一切剖面测量的入口，终审指定为下一里程碑。
2. **虚线信号缺失可能是物理性的**：近距运动模糊把虚线灰化 ⇒ 虚线可能在小 d 端
   天然不可检出，剖面法有效下限被抬高（与带长上限共同压窄可用 d 窗）。
3. **剖面法有效范围窄且目前是模型预测**：交集 d∈[47,100]（≈2 个虚线周期）依赖两个
   未实测假设（P=15m、行分辨率 3px），非实测可用范围（记号约定 §7）。
4. **绝对标尺无独立锚**：两条路径都依赖外部事实（国标 P / 「1 分/米」口径三方来源
   待复核），且共用投影模型前提（§8）；采数被两道闸挡住（重新启用里程读取的工程
   改动＋「离线标定用途」口径落字）。
5. **对象族边界不清**：景物/路面/高光按什么物理属性分族，影响混合池能否被拆干净。

**A_z→V 映射链（终审点名要显式化）**：

```
几何    d_px = f·H / Z                    （地面点纵距，px）
        ḋ_px = V · d_px² / A_z ，A_z = f·H [px·m]
⇒       V = ḋ_px · A_z / d_px²            （A_z 是乘积，只需定出乘积即可换 V）
乘积分解（f 与 H 单独不可辨识）——三选一物理锚：
 (i)  H 直测：无锚可用，出局；
 (ii) hfov→f：f = (W/2)/tan(hfov/2)，H = A_z/f —— 依赖渲染配置读数（未核）；
      合理性检验区间见 §9-Q1；
 (iii) 长度锚：路径 I——虚线周期指纹 p_px = P·d_px/H ⇒ H = P·d_px/p_px
```

## 7. 不确定性记号约定（终审 3-2）

- **「X~Y ±p~q」**（如 322.7~323.2 ±1.6~2.5）：第一段=**场次间中位数的极差**；
  第二段=**场内散布的场次间极差**。都不是置信区间。
- **「±SE」**：bootstrap 标准误，重采样单位**随文注明**（按轨/按线）；n=2 线时
  SE 标注「无意义」，不得引用。
- **「d∈[47,100]」**：剖面法**模型预测区间**（输入假设 P=15m、行分辨率 3px），
  与实测可用区间分列；实测值出来后替换并记入 README。
- **「零检出」**：**0 次观测**，不是带置信上限的估计；「_fit_yellow_edges 失败率
  0%」同理是观测比例，非上界。
- **「r²=0.12」**：单变量线性模型的解释方差比（max-over-lags 取峰值），不是置信度，
  且经 3 候选选择需按候选数打折理解。
- **「相容」**：读数落在模型族预测内（如 1.48 vs 1.50 仅 0.6σ），不构成验证。

## 8. 双锚共享前提清单（路径 I/II 独立性审查，终审 3-4）

两条路径**共用**以下前提，全部通过审查前，同一 P 只能计为「同一前提下的两种计算
一致」，不得计为互证：

|---|---|
| 投影模型成立（d_px=f·H/Z）——注意这正是 Gate 3 待判命题本身 | 未闭合（O1）；两锚只锚**标尺**，不裁决模型族 |

| 外部事实：国标 P=15m（I）／「1 分/米」三方口径（II） | 各自外部，互不依赖——**这是两路唯一不共享的部分** |
