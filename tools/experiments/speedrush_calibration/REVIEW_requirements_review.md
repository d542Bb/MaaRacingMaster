## 1. 一句话结论

驾驶的主线方案（控制路线·模块化栈）自 09-17 定稿后**没有缺过能力设计**；缺的是
§3 表里列出的若干**前置量与一次单位口径判决**。被实验连续三天追打的「从地面流速
测车速」在仓库检索中找不到任何书面需求——它是标定实验审查过程中自行生长的命题，
立项文档无此目标（证据 §4）。**裁定已于同日收回（§6）：路面腿砍掉（Q3）、尺子用完
再收杆（Q4）、远近排序口径认、车速优先不自屏幕读（Q1）；裁后动作序 §6.1。**

## 2. 目标与验收（复抄行为契约，只给指针）

目标 = 驾驶阶段自动跑完整局（阶段 1+2），按收益模型选择横向目标，正常结束回 UI；
**终点判据是跑完，不是拿分**。验收六条（跑完不卡死 / 金币获得率优于直行基线 /
控制回路 P95 进帧预算 / 抉择质量对齐演示者 / 换车不变 / 多局稳定）与七条不变量的
真源 = [`docs/plan/speedrush-control-route.md`](../../../docs/plan/speedrush-control-route.md)
「〇、行为契约」。**「需要什么」全部由这六条验收反推**：每条验收成立需要哪个观测量
可信，就需要什么；不在反推链上的量，产品不需要。

## 4. 为什么「地面流速测速」不在清单上（生长链举证）

1. **立项任务从未包含它**：外部咨询稿的目标写法 = 横向车道坐标 ±0.25 车道
   （`EXTERNAL_BRIEF.md` :21-22）；纵向尺度 = 「HUD 米速钉」（control-route 状态块原文）；
   Gate 3 判据「虚线回流≈HUD 速度 ±15%」本身拿 HUD 当参照——定位是**自洽校验**。
2. **命题出现在复审而非立项**：「A_z→V 映射」字样首见终审阻塞复审
   （`REVIEW_gate3_status.md` §5；`6e7389f`/`7716964`），README 头部与咨询稿均无此目标。
3. **仓库内未检索到消费者**（2026-09-21 全仓检索）：运行期代码未见速度/米制距离消费方
   （`module.py`/`hud.py`）；计划文档三项「解锁」逐字核对后所需量为：§7#2→横向归一（A1）、
   阶段 B 距离→rank（A3）、阶段 C 输入→HUD 侧已实测到手。**边界声明已闭合**：
   维护者确认不存在未写入文档的此项需要（§6-Q3 裁「砍」），本节结论定稿。
   调查记录对应 direction_review §5-2。
4. **但不可丢弃的产出**：A1 尺子、撤回清单的证据链、对象身份先于统计等纪律资产
   （direction_review §2-5/6）——收杆时按 §5 迁移，不是清零。

## 6. 问题清单与维护者裁定（2026-09-21 问，同日答）

- **Q1 速度源与远近语义**：车速是否以屏幕得分速度为准、远近是否只需排序。
  **【裁】** 远近排序口径**认**。速度方面以维护者反问定调：**油门在程序自己手里，
  车速不应首先当传感器去读**——A2 相应降级；仅当闭环确需实测车速时启用屏幕读数，
  使用前提 = 能从读数拆出速度基值（离线口径已有：读数 >50 弃、窗口中位取底值）。
- **Q2 0.83 对账排期**：屏幕速度底值与里程面板换算的差，查还是挂？
  **【裁】** **查**——列动作序①（它同时定底值口径与「1 分=1 米」折算）。
  **〔完成 09-21〕**分解为简并二假设（计数窗 ≈8.2s vs 1 分≈1.22 米），两读法下游同果：
  车速锚=底值；左卡片周期值 ÷10s 禁用。定案 = README「0.83 对账轮」。
- **Q3 路面腿处置**：缩窄 Gate 3 定义还是维持原出口？
  **【裁】** **砍掉**（后果记录 §5）。
- **Q4 收杆节奏**：立即归档还是贴近重测用完尺子再收？
  **【裁】** **用完再收**（动作序④完成后走⑤）。
- **Q5 天气可控性**：**【裁】** 纯随机不可指定，但**重开一局可换天气**——
  需要晴天素材时换局重摇即可，「晴天等不到」的前提不成立。
- **Q6 雨天黄线**：**【裁】** 湿景黄线**肉眼清晰可见**（维护者观察）——游戏侧
  可见性成立，实验管线的黄缘变暗失效是我方阈值口径问题；运行期专门实测不立案，
  并入阶段 B 回归顺带验证。
- **Q7 路肩宽度**：**【裁】** 路肩与车道**一样宽** → 影像间距比 0.826 判给线位破损
  管线的伪读数，**销案**；游戏事实已回写 RULES（该 83% 与 Q2 的 0.83 系同数巧合）。
- **Q8 金币线普遍性**：**【裁】** **局局都有** → B1「看车不看币」保留，无需加
  适用域限定；游戏事实已回写 RULES。
- **Q9 τ 实机排期**：**【裁】** **下一阶段**——随阶段 B 开工排，不抢收杆动作序。
- **Q10 台账补记**：**【裁】** **补**（动作序②）。
