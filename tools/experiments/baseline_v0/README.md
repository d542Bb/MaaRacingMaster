# baseline_v0 — 固定协议的可比驾驶基线（活跃）

status: active

**问题（可证伪）**：同一版本、同一协议下，第二阶段得分与运行稳定性的
局间波动有多大？在这个波动量级没有测出来之前，不做任何版本比较。

**只读**：探针只读 `logs/<token>/trace/speedrush.jsonl` 与
`speedrush_summary.jsonl`，不写生产数据、不改控制。

## 协议（冻结）

**固定项**：代码 commit、机器、感知/深度配置、比赛回合与车组、程序驾驶、
开局流程。每次会话开始前记录 commit 与回合，写入会话备注（本地，不入库）。

**不可固定项**：赛道路径。游戏没有选图机制，路径每场随机生成（RULES §4.7）；
路径差异计入方差，**不允许事后挑选“看起来同赛道”的局**再做比较。

**重复次数**：10 局，分两段会话各 5 局（同一版本），用于区分局内与跨会话波动。

**碰撞**：v0 不测。当前没有碰撞数据源（血量格未读、胜负在结算屏）；异常局
保留录像供后续另立口径，**不得用“速度骤降”之类未校准代理冒充碰撞率**。

## 指标（跑之前定义，跑完不改）

| 指标 | 定义 | 来源 |
| --- | --- | --- |
| 主：得分速度 | 阶段 2 `score / (dur_s/60)`（分/分钟） | 局汇总 `score`、`dur_s` |
| 辅：得分 | 阶段 2 末次 HUD 读数 | 局汇总 `score` |
| 辅：时长 | 阶段 2 `dur_s` | 局汇总 |
| 稳定性：拍间隔 | 决策拍 `dt` 的 p50 / p95 | trace `dt` |
| 稳定性：计划失效率 | `plan.valid=false` 拍数 / 有计划拍数 | trace `plan` |
| 稳定性：保守段 | `CONSERVE/FAULT` 拍数与连续段数 | trace `state` |
| 稳定性：转向抖动 | 相邻巡航拍 `abs(Δsteer_norm)` 的 p95 | trace `steer_norm`、`state` |

阶段 1 只报不判：现有六局里它的变异系数约 42%（最低 242、最高 2633），
不足以稳定区分版本；主判据固定在阶段 2。

## 停止规则

1. 每段会话结束后先算中位数 / 四分位距 / 最小最大 / 变异系数，不先做版本解读。
2. 主指标变异系数 **> 25%**：停下来查路径、车组、感知供数差异，**不加局**。
3. 两段会话的主指标中位与四分位距明显重叠之前，不比较任何两个版本。
4. 0 分或异常短的局不剔除，单独列出并注明原因；剔除会掩盖失败模式。

## 运行

```bash
.venv/Scripts/python.exe tools/experiments/baseline_v0/probe_baseline.py \
    --tokens 20261029_XXXXXX_1,20261029_YYYYYY_1
```

输出：逐阶段指标表、阶段 2 的汇总统计、冻结记录（commit 与策略文件摘要）。
`--json out.json` 可导出同口径结果。
