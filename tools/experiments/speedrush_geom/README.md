# speedrush_geom — 几何供数能否取代深度（C 类实验）

## 目的

验证一条**不依赖深度网络**的在线供数链能否取代当前深度关键路径：

- 自车运动：地面逆透视（IPM）+ 亮度相位相关，不做颜色阈值/语义匹配；
- 走廊几何：LSD 线段 + RANSAC 二次拟合，边缘几何而非颜色；
- 目标距离：YOLO 框底点 + 地面平面测距，已知车宽做远距旁证；
- 全程记录延迟，和现有深度链（MoGe/点云/融合位姿）做交叉验证。

## 方法

- 标定：`gate0.json` 的地平线 `y_h`；相机高度 `h`、焦距 `fx/fy` 作为实验参数显式记录，
  并用车道宽度（3.38 m）做尺度核对。
- IPM：`v = y_h + fy·h/Z`，把下半个画面重投影成米制 BEV（x ±10 m，z 3~45 m）。
- 自车运动：BEV 亮度相位相关，取前向/横移位移；响应值作为置信度。
- 走廊：LSD 线段端点投到 BEV，左右两侧各做一次带外点剔除的二次拟合，
  输出 z=10/20/40 m 处的中心、宽度和曲率。
- 目标：YOLO 框底点 → 地面平面距离；远距用已知车宽做第二估计，两个估计都记录。

## 交叉验证

- 同一段回放上同时跑几何链与深度链：
  - 速度/横移/航向：几何 BEV 位移 vs `probe_3d_fusion` 的逐帧位姿；
  - 目标距离：几何框底点 vs MoGe 点图在同像素的 Z；
  - 走廊：几何 LSD 拟合 vs 深度链的左右边线。
- 按距离带统计：0–15 / 15–40 / 40–80 m。
- 没有绝对真值，判据是**多方法一致 + 分歧可解释**；分歧帧留样人工复核。

## 取代判据（先定，后跑）

- 延迟：几何链关键路径 < 16.7 ms/帧（1280×720）。
- 速度：与深度链/虚线通过率在高速段偏差 < 10%。
- 横位/航向：有标线帧与深度走廊偏差 < 0.3 m / 1°。
- 目标距离：0–20 m 偏差 < 0.5 m 或 10%；20–40 m 允许更大但必须标置信度。
- 失效：无标线/低纹理时输出低置信或未知，不允许静默给错值。

## 探针索引（2026-10-28 补）

带 ◆ 的三个同时登记在根级 `speedrush_trace_consumers.md`（#23-25，含迁移破坏点）；
其余只在本目录使用。

**第一批——`RESULTS.md` 的数就是从这两个来的**
- `probe_geom_vo`：几何链本体（IPM 逆透视 + 亮度相位相关 + LSD 二次拟合 + 框底点测距），
  速度 / 走廊 / 延迟三张表都是它跑的，`--render` 出叠加图。
- `probe_crossval`：几何链 vs 深度链逐帧对拍——速度比值、目标距离按距离带误差、走廊宽度对比。

**下一步 1：换掉相位相关测速（RESULTS 判为关键阻塞）**
- `probe_repeat_and_flow` ◆：先把**速度真值**修到可信（里程面板三道判据：暗底闸门 / 裸整数 /
  Δ合计−Δ里程 必为 30 的倍数），再谈两条通道谁胜；裁判不合格时 flow 数字不进任何结论。
- `probe_barrier_rate`：板缝过缝率测速——墙面固定列亮度以 f=V/s 振荡，**频率测量**不受重复
  纹理的对应歧义影响。先验三条：峰要突出、左右两侧与不同时间窗一致、反推 s 是 plausible 常数。
- `probe_ground_corr_audit`：信息量闸门——下一拍究竟有多少**可被人确认是同一处**的静态地面
  对应点。它把「信息瓶颈」与「算法找不到」分开，两者指向相反的下一步，自制置信度分不开。

**下一步 2：走廊稳定化**
- `probe_center_defs`：同一栅格的三种路心取法（全带中位 / 固定 6~9 m 窄窗 / 逐行中心直线拟合）
  在抖动、弯道偏差、与找边分歧上的差别；没有独立横向真值，所以只比可测量、不比"准"。
- `probe_plane_hold` ◆：共模跳变归因——区域路心逐拍跳 1~2 m 时，平面坡度与点云各占几成
  （A/B/C/D 四个反事实按 Shapley 拆）。
- `probe_ego_attitude` ◆：平面姿态每拍可用吗（抖动 / 动态范围）、相机与车身是否刚性、界面
  横幅（事件横幅在拟合带内）污染了多少。

**总装**
- `probe_stack_overlay`：无深度快速栈把「路的范围 / 车身方向 / 速度 / 目标」四样画回帧上人工
  判读，逐帧记时延；相位相关的失败样本一并记录，不粉饰。
