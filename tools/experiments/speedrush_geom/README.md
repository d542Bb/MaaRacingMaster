# speedrush_geom — 几何供数能否取代深度（C 类实验）

## 目的

验证一条**不依赖深度网络**的在线供数链能否取代当前深度关键路径：

- 自车运动：地面逆透视（IPM）+ 亮度相位相关，不做颜色阈值/语义匹配；
- 走廊几何：LSD 线段 + RANSAC 二次拟合，边缘几何而非颜色；
- 目标距离：YOLO 框底点 + 地面平面测距，已知车宽做远距旁证；
- 全程记录延迟，和现有深度链（MoGe/点云/融合位姿）做交叉验证。

## 方法

- 标定：`gate0.json` 的地平线 `y_h`；相机高度 `h`、焦距 `fx/fy` 作为实验参数显式记录，
  并用车道宽度（3.38 m）做尺度核对。
- IPM：`v = y_h + fy·h/Z`，把下半个画面重投影成米制 BEV（x ±10 m，z 3~45 m）。
- 自车运动：BEV 亮度相位相关，取前向/横移位移；响应值作为置信度。
- 走廊：LSD 线段端点投到 BEV，左右两侧各做一次带外点剔除的二次拟合，
  输出 z=10/20/40 m 处的中心、宽度和曲率。
- 目标：YOLO 框底点 → 地面平面距离；远距用已知车宽做第二估计，两个估计都记录。

## 交叉验证

- 同一段回放上同时跑几何链与深度链：
  - 速度/横移/航向：几何 BEV 位移 vs `probe_3d_fusion` 的逐帧位姿；
  - 目标距离：几何框底点 vs MoGe 点图在同像素的 Z；
  - 走廊：几何 LSD 拟合 vs 深度链的左右边线。
- 按距离带统计：0–15 / 15–40 / 40–80 m。
- 没有绝对真值，判据是**多方法一致 + 分歧可解释**；分歧帧留样人工复核。

## 取代判据（先定，后跑）

- 延迟：几何链关键路径 < 16.7 ms/帧（1280×720）。
- 速度：与深度链/虚线通过率在高速段偏差 < 10%。
- 横位/航向：有标线帧与深度走廊偏差 < 0.3 m / 1°。
- 目标距离：0–20 m 偏差 < 0.5 m 或 10%；20–40 m 允许更大但必须标置信度。
- 失效：无标线/低纹理时输出低置信或未知，不允许静默给错值。
