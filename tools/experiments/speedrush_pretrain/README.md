# speedrush_pretrain — 现成车道模型在《巅峰极速》画面上认不认得车道

## 要回答的问题

深度模型（MoGe）供得出几何但慢，社区里现成的预训练车道线网络（真实道路数据训练，
如 LaneNet 系）能不能直接顶上「路的范围」这一栏。本实验只回答**认不认得**：
把预训练网络的输出叠回游戏帧人工看，不评精度、不调参、不接任何生产链（C 类实验）。

## 范围与产物

- 只读离线回放帧（用法见探针 docstring）。
- `probe_lane_first_look.py`：唯一脚本——加载权重、跑单帧、把网络输出叠回游戏帧并拼成
  `first_look_grid.jpg`。它不是精度评测器：不调参、不算 IoU、不接生产链。
- `weights/lanenet_multihead.onnx`：待试的预训练权重（来源见探针脚本注释）。
- `first_look_grid.jpg`：首眼叠图，人工判读的证据面。

## 结论

首眼判读结论未归档——本目录停在"权重能跑、画面叠出来了"这一步；是否值得继续
（域差大到什么程度、要不要微调）按本目录产物的判读另行定档，退役时按实验区
四步收口把结论迁走、过程留在提交历史里。
