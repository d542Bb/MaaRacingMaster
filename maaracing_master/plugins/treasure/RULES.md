## 1. 回合结构

每局**最多 5 回合**（R1~R5）。每回合系统给出**系统报价 H**（智能出价弹窗中心金额，程序从输入框读取，只取每回合第一次读数）。`[权威]`

**附加回合**：第 5 回合出现**第一名 = 第二名平局**时，追加第 6 及以后回合继续拍到分出胜负。附加回合的出价数据统一并入第 5 回合槽位。`[权威]`

**成交回合**：某一回合满足成交条件（见 §2）即在**当回合成交**，不再进入后续回合。

**每回合可放弃**：玩家某回合可以不出价——超时未操作或主动填入 0，两种情况该回合出价均记为 **0**。因此出价数据中 **0 = 该玩家该回合放弃/未出价，不是数据缺失**；统计出价顺位时只计有效（> 0）报价。`[权威]`

## 2. 成交判定（提前成交 / 一口价）

**成交条件**：当回合 **第一名出价 ÷ 第二名出价 ≥ K_r** 时，当回合立即成交，**第一名拍中**；未达标则进入下一回合。`[权威]`

**K 值表**（按回合递减）：

| 回合 | R1 | R2 | R3 | R4 | R5 |
|---|---|---|---|---|---|
| K_r | 2.0 | 1.6 | 1.3 | 1.1 | 1.0 |

**关键口径**：基准是**当回合第一名与第二名的出价比值**，**与系统报价 H 无关**。`[权威]`

> 历史误记警示：早期曾误作"成交 = K × H"，已作废（2026-08-16 二版更正）。凡见到"K×H"表述均为旧错。

R5 的 K = 1.0 意味着**第一 > 第二即成交**，平局才加赛。

**验证例证**（全部场次吻合，`[实测]`）：

| 场次 | 回合 | 第一名 / 第二名 | 比值 | 判定 |
|---|---|---|---|---|
| g9 | R1 | 179,500 / 81,600 | 2.20 | ≥ 2.0 成交 ✓ |
| g12 | R3 | 400,000 / 252,706 | 1.58 | ≥ 1.3 成交 ✓ |
| g10 | R4 | 360,588 / 277,376 | 1.30 | ≥ 1.1 成交 ✓ |
| g4 | R5 | 245,500 / 222,222 | 1.10 | ≥ 1.0 成交 ✓ |

## 3. 收入机制（本场收入）

**本场收入**分两类，规则完全不同：`[权威]`

### ① 拍中者（第一名，触发成交）

```
本场收入 = 利润 = 拍品总价 − 最终竞拍价
```

正值 = 赚，负值 = 亏。**拍中者收入即其利润**，不存在"分红"概念。

### ② 未拍中者（第 2/3/4 名）

**只有拍拍中者亏钱（收入 < 0）时才有收入**，且按**成交回合的出价高低顺位**从拍中者的亏损额中分红：

| 出价顺位 | 分红比例 |
|---|---|
| 第 2 名 | **15%** |
| 第 3 名 | **10%** |
| 第 4 名 | **5%** |

**若拍中者正利润（收入 ≥ 0），其他所有玩家收入为 0。** 亏损为 0 同样无分红。

**验证例证**（`[实测]`，与落盘数据逐一吻合）：

| 场次 | 拍中者盈亏 | 我方顺位 | 我方收入 | 验算 |
|---|---|---|---|---|
| g8 | 亏 224,696 | 第 3 | 22,469 | 224,696 × 10% ✓ |
| g6 | 亏 145,742 | 第 2 | 21,861 | 145,742 × 15% ✓ |
| g12 | 亏 131,867 | 第 4 | 6,593 | 131,867 × 5% ✓ |
| g5 | 利润 0 | 第 2 | 0 | 无亏损即无分红 ✓ |

### 未拍中的出价不花钱

未成交（未拍中）玩家的出价**不产生任何支出**——这是分红机制能成立的原因。`[权威]`

## 4. 计分目标（单日最高分）

**单日最高分 = 单日最高「单场收入」**（不是利润）。`[权威]`

- 赢（拍中且有利润）能刷新；
- **输出了一笔分红也是收入**，同样能刷新——即"输着也能刷分"。

验证：2026-08-16 单日最高分 22,469，正来自 g8 场的第 3 名分红。`[实测]`

## 5. 对手行为约束

① **对手池每场随机**，不可跨场预测对手风格，每场须从零观察。`[权威]`

② **对手出价可下调**——出价**非锁定、不可撤但可改低**。`[权威]`

> ⚠️ **由此直接否定的错误假设**：「贴第一即安全」「严格低于对手最高价即 100% 安全」。
> 第一名随时可能下调退出，我方贴上就变第一接盘。凡基于"贴第一"设计的打法与真实规则相悖。

## 6. 未知区

**以下事项尚无确证，禁止当作已知规则使用。** 需要时先做最小实验（记入 `tools/experiments/`）或向用户确认：

| 未知项 | 状态 |
|---|---|
| 提前成交的**精确触发时机**（是否仅回合末结算、还是出价提交即判） | 未定性，优先级最高 |
| 成交回合的**顺位规则细节**（并列时如何取顺位） | 未逐场核对完 |
| 对手**撤价频率与幅度**分布 | 未统计 |
| **最小有效加价单位** | 已证最小单位 = 1（非 100），但"最小加价是否有下限"未确证 |
| 彩蛋发放条件与数量分布 | 未定性 |

> 已证伪的推导（勿再引用）：由"相邻差价最小值 = 100"推出"最小货币单位 = 100"——前者是样本最小值，不等于规则允许的最小差值；真实出价含大量非整百值，**货币单位就是 1**。`[实测]`

## 7. 术语表

| 术语 | 含义 |
|---|---|
| 拍中 / 中标 | 触发成交的第一名，取得拍品 |
| 成交价 | 最终竞拍价（拍中者的出价） |
| 拍品总价 | 系统给出的藏品估值锚 |
| 本场收入 | 拍中者 = 利润；未拍中者 = 分红（可能为 0） |
| 利润 | 仅拍中者概念：拍品总价 − 成交价 |
| 分红 | 仅当拍中者亏损时，按顺位分给 2/3/4 名的亏损额比例 |
| 出价顺位 | 成交回合各玩家出价的高低次序（只计 > 0） |
| 成交回合 | 满足 K_r 条件的那一回合 |
| 提前成交 / 一口价 | 前 4 回合即达成交条件，未拖到 R5 |
| 彩蛋（红 / 黄 / 蓝） | 每日任务奖励，与竞拍收入分属两套账 |

> 本域术语（拍中/成交价/赛道类）与**竞速模块**（赛道/圈速/油门/刹车）严格分离，不得混用。
